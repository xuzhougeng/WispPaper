# 保存笔记到 Notion

在「设置 → 自定义 → 添加连接器」填写官方地址 `https://mcp.notion.com/mcp`，令牌留空，点击连接并完成浏览器登录。也可继续使用已授权的 `npx -y mcp-remote https://mcp.notion.com/mcp` 命令连接器，或填写官方地址与 MCP 令牌。只启用一个 Notion 连接器。

连接后显示 Notion 返回的账户名称、邮箱和工作区，点击「账户详情」可展开账户标识，保存预览中也显示接收账户。接口未提供的名称或邮箱会明确标注缺失，不根据邮箱域名等信息推断。在「设置 → 自定义 → 已连接的 Notion → 设置 Notion」设置笔记归档；「测试连接」可刷新资料。

## 保存位置

「Notion 父页面访问链接」可填入已创建的普通页面链接，包括 `https://app.notion.com/p/标题-页面ID?source=copy_link` 和 `https://www.notion.so/…`。需要该账号有权在页面下创建内容。不要填数据库链接。

默认层级：

```text
指定的父页面
└── WispPaper笔记（根页面名称可修改）
    └── 文献库名称
        └── 期刊 出版年份 文献题目
            ├── 文献基本信息
            └── 我的笔记／提问、原图与 AI 回答
```

根页面名称非空时，父页面留空会在第一次手动保存时于 Notion 私人首页创建「WispPaper笔记」，其下保持同样层级。填入父页面后，根页面名称同样生效；该父页面下已有唯一同名根页面时会复用。填入的链接本身就是同名根页面时，直接使用，不再嵌套一层。它是私人根页面，不是工作区公共首页。连接、测试连接和修改设置不会创建页面。

根页面名称默认是「WispPaper笔记」，也可清空。清空后省略这一层：`指定父页面 → 文献库名称 → 文献笔记`；父页面链接也留空时，改为 `Notion 私人首页 → 文献库名称 → 文献笔记`。设置示例与保存路径同步上移一级，不创建空标题根页面。后续保存仍复用该位置的文献库和文献页面，并按来源去重；旧位置的页面不会自动移动或删除。

文献库分组固定保留，不再提供页面层级选择。「文献笔记标题」可选择「组合字段」并调整顺序，或选择「自定义输入」在保存前逐篇命名。组合字段生成的页面名较长时自动截断，不提供最大字符数设置；已有页面不会因组合设置变化而自动改名。「文献基本信息」也支持调整所选字段的顺序，预览同步更新，题目字段显示为「题目」，已关联页面的头部不自动改写。正文默认保留完整题目。缺少的字段不补造；出版日期按实际精度保存为年、年月或年月日，旧记录不会自动推断月份和日期。作者中的明确「姓, 名」格式转换成「名 姓」显示，不补全缺失的名字，不改变原文献库的作者数据。

日期选项按用途区分：标题组合中只提供「出版年份」；基本信息中只提供「出版日期」，有完整日期时显示为 `YYYY-MM-DD`，只有年或年月时保留已有精度。旧设置中标题的「出版日期」会转为「出版年份」，基本信息的「出版年份」会转为「出版日期」，合并重复项并保留顺序。旧全局标题模板仅用于识别原先选择的自定义模式，不再套用到各篇文献。

选择「自定义输入」后，设置页不填写共享标题模板。完成问答或「我的笔记」编辑并点击「下一步：填写标题」时，打开本篇文献的标题窗口，必须手动输入非空单行标题，点击「保存到 Notion」后才开始网络写入。返回编辑或在标题窗口按 Escape 保留笔记草稿和已经输入的标题；再次打开新的保存窗口时标题输入为空，不会沿用其他文献的标题。输入按字面保留，不解析变量、不自动截断。目标已有同篇文献的笔记页面时，明确确认的手动标题会更新该页面名称，正文、页面链接和追加去重规则保持。库级问答仍使用固定的「文献库问答」，不要求输入单篇标题。

库级提问保存到所属库的「文献库问答」页面。旧版层级设置会被忽略。修改根页面名称或父页面，只影响后续保存位置，不移动旧页面。库和文献改名后，其已关联的页面继续使用；同一个根页面通过自身链接或父页面链接访问时，复用同一套文献笔记。

## 手动保存

1. 在单篇或文献库提问中，等待回答完成。
2. 点击回答下面的「保存到 Notion」，或顶部的「保存对话到 Notion」。
3. 保存对话时，先选择当前文献的一个或多个历史对话，再点击「下一步：选择问题」。库级提问列出所属库的库级历史；不会混入其他文献的历史。默认选择当前对话。
4. 跨对话按提问时间勾选问答，可用「上移」「下移」调整本次写入顺序。旧记录没有逐题时间时按对话创建时间及原顺序排列，默认勾选未保存的问题，可全选／取消全选。「已保存」的问题可以勾选后编辑为新版本；「待核实」的问题暂不能勾选。没有完整回答的问题不导出。点击「下一步：提炼问题」。
5. 可选：点击「全部提炼」，或对单个问题点击「提炼」。对照原问编辑提炼稿，点击原问或提炼稿卡片选择版本；点击输入框只编辑文字，再进入笔记编辑；默认保留原问，也可「跳过，直接编辑」。停止、返回或关闭窗口会停止后续排队请求，已生成的稿件在当前窗口内保留；关闭窗口后丢弃这些临时稿件。
6. 核对保存路径并编辑选中笔记的 Markdown。原图占位行会替换成实际附件，删除完整占位行可移除该图片。返回选择不会丢失编辑内容，保存失败时窗口保留草稿。单轮问答也可跳过提炼直接编辑。
7. 选择「自定义输入」时，先点击「下一步：填写标题」并填写本篇标题。最后点击「保存到 Notion」。所选历史写入同一文献页面，每条 Q 使用三级标题，不附对话标题。后续问答依选择顺序追加到页末，其他对话与手工内容保留。单篇文献的信息区域出现「Notion：页面访问链接」；库级提问顶部显示「Notion 笔记」。

文献信息中的「我的笔记」下方同样提供「保存到 Notion」，会打开编辑窗口并保存到该文献对应的笔记页面。导出时的编辑不改写本地原问答或「我的笔记」。

「设置 → AI → 任务」新增「科研问题提炼」，可单独选择文本模型，默认跟随助手模型。提炼界面也可通过模型菜单更换此任务的模型。仅在点击提炼时请求 AI，发送原问题、对应回答与基本信息的节选，不上传原图或整篇 PDF。提示词要求保留研究意图、范围和不确定性，不补造事实，不强化因果；对应回答被明确标为未经核实的上下文。输出只是可编辑的表述建议，不是科学性或事实核验。采用稿仅替换导出笔记的 Q 标题，回答、图片、原文摘录和原始对话保留。手动改过的笔记标题不会被静默覆盖；可跳过提炼保留现有编辑。修改后的导出内容仍按原问题来源与版本去重。

问答的默认格式以问题作为三级标题，原图和回答放在其下，便于在同一篇文献的笔记中按问题浏览：

```markdown
### Q：这图什么意思

![原图](wisppaper-image://图片ID)

A：回答内容……
```

问题附带的原文摘录和多行内容保留在问题标题下。问答正文中的一级、二级标题自动调整为三级；代码块保持原样。已有笔记不会因默认格式变化自动改写。

「设置 → 自定义 → 已连接的 Notion → 设置 Notion」底部提供「保存效果示例」，展示页面层级、所选文献基本信息及 Q／原图／A 排版。根页面名称、标题组合和信息字段变化会同步反映在示例中；示例只在本机显示，不创建或修改 Notion 页面。

保存会追加内容，按对话 ID、问题来源和内容版本跳过同一目标中成功保存的相同版本；不同历史中的相似问题分别保留。编辑后的新版本可追加为新笔记。已有页面的其他内容保留。新笔记不附加「来自 WispPaper」或自动生成的「引用文献」尾注，回答原文中的引用保留。页面被移出配置的父页面范围时，保存停止。历史内容保留，新写入的内容不分组。

图片通过官方 MCP 获取上传地址，再将原图上传到 Notion，并使用返回的持久引用。单张上限为 20 MiB，工作区的套餐限制仍适用。没有自动压缩或上传到第三方图床；图片上传失败会报告为未完整保存。

页面映射、成功保存记录与附件引用保存于设置文件旁的 notion.sqlite；文献库中保留已确认页面的访问链接。本地记录用于跳过重复保存，升级兼容旧版来源标识，但新内容不再写入可见标识。网络中断后若无法确认创建或追加是否完成，会停止并提示核实，不盲目重复写入。不要在结果待确认时反复改目标或删除本机索引；成功保存记录属于本机，换设备不会自动同步。

如果页面已创建，但追加问答被 Notion 明确拒绝（例如参数校验错误），修复后可对同一问答重新保存，继续使用已有页面。父级路径未返回时，会通过父页面内的原生子页面块核对位置，普通访问链接不能作为层级凭据。

自动管理的根页面已被删除时，下一次保存会在指定父页下创建或复用新的同名根页。明确填写的父页面被删除时停止，不改写到其他位置。

## 本地试运行

可用单独的数据目录试用，避免混入正式文献库。全新目录可先用仓库的 seed 示例创建样例库；已有演示库时跳过第一条命令：

```powershell
cargo run -p wisp_core --example seed -- target/notion-demo
$env:WISP_PAPER_HOME = (Resolve-Path 'target/notion-demo').Path
cargo run -p wisp_paper
```

检查指定父页下的根页、已有同名根页复用、根页面本身的链接、默认私人根页，以及问题勾选、笔记编辑、移除原图、我的笔记、库级提问、连续追加、重复点击和重启后的链接。再在 Notion 手工添加一段内容，确认后续追加保留它。测试时使用专门的 Notion 页面。

不连接真实账号的自动检查：

```sh
cargo test -p wisp_core -p wisp_net
cargo check --workspace
cargo clippy --workspace --all-targets
```

真实连接和 Notion 图文显示仍需要在本机授权后试运行。自动测试不会访问或写入真实 Notion 工作区。

另有一项默认忽略的 Windows 真实写入测试 `notion::tests::live_multi_history_write_and_readback`。仅在明确授权写入测试数据后启用：在 Windows 测试进程中设置 `WISP_NOTION_SMOKE_SETTINGS` 为已连接账号的本地 `settings.json` 完整路径，再单独运行该测试并传入 `--ignored --exact --nocapture`。它会在配置的根页下使用「Notion 写入验收（测试）」文献库分组和带 `[测试]` 的文献页面，验证两段对话、同名图片 ID 的不同原图、编辑内容、排除未选问题、重复保存、新问题按序追加，以及保留手工内容；读回通过后打印验收页链接。它不会打印令牌，不属于常规离线测试，也不会删除测试页面。
