# 功能详解

## 多个独立的文献库

启动后的首页是文献库列表。每个文献库有自己的名称、主题描述和标识色，是数据目录下的一个独立文件夹（数据库、PDF、自定义词条都在里面），可以单独备份或拷走。首页的文献库按建立的先后排列，打开一个不会改变顺序；把一张卡片拖到另一张上，它就换到那个位置，这个顺序会记住。

## 先聊，后建库：首页的助手

不必先建文献库。首页右下角的圆按钮是助手：点开是对话页，上面是输入框，下面是「最近对话」。说一个想法（「帮我调研一下……」），或者点输入框左边的加号、把 Word 稿件（.docx）或 PDF 拖到首页（会打开对话页、文件放进输入框），再发出第一个问题。输入框下面的「调研一个想法」「审一份稿件」「找几篇文献」「从 Word 建文献库」只往框里放一句开头（审稿件和从 Word 建文献库会先让你选文件），不会自己发出去。左上角「← 首页」或 Esc 回到首页，没发出去的字和文件留着。

- 发出第一个问题时才会建立这次对话；只是打开首页或打字，不会在磁盘上留下任何东西。对话按第一个问题命名，右键可以重命名。
- 对话页只有这次对话：没有侧栏和文献库的导航，左上角「← 首页」回去；上方的「历史」列出其他对话，「新对话」回到空的对话页。助手知道还没有文献库，需要文献时自己到 PubMed、Europe PMC、Crossref、arXiv 检索；值得留下的文献它会用检索式导入（导入前先问你），上方「文献 N」列出这次对话收进的文献。
- 拖进来的 Word 文件是要审的稿件，显示在对话右边，窗口够宽时再右边是批注栏。助手把意见作为批注留在稿件对应的原文上（只在原文里找得到的才留下），改不改由你逐条决定；稿件上方的「导出」可以得到带批注的 Word 文件。拖进来的 PDF 成为这次对话的一篇文献。
- 「从 Word 建文献库」：选一份写好的 Word 稿件，发出后助手读出它参考文献表里的每一条（带 Zotero / Mendeley 引用域的直接取域里的文献信息，否则按「参考文献」「References」后面的条目逐条读），征得你同意后收进这次对话：有 DOI 的按 DOI 到 Crossref 核对，没有 DOI 的按条目文字到 Crossref 查（题目、年份都对得上才采用）补上 DOI 和期刊信息。读不出来的条目不会凭空补写，助手会逐条告诉你；只按文字读出、没能核对的也会提醒你核对。对话以「<文件名> 的参考文献」命名，Word 文件不会被改动，也不会作为待审的稿件显示；收完后点「建成文献库」就是一个文献库。同一件事在文献库的助手里也能做：附上 Word 文件，说把参考文献收进来。
- 「最近对话」按时间列出这些对话：标题、收进的文献数（有时才写）和日期。右键可以重命名、建成文献库或删除；删除和移除文献库一样，只是把文件夹移到数据目录的 removed 下。
- 聊出眉目后点对话上方的「建成文献库」：在新建文献库的对话框里填名称、主题和标识色，名称旁的星形图标可以让模型按这次对话拟名称和主题。确认后窗口就地变成这个文献库，侧栏出现，对话接着进行；收进的文献就是文献库的文献，什么都不用搬。
- 这些对话不在 `wisp list_libraries` 和 MCP 的文献库列表里，也不算在「只有一个文献库时可以省略」之内；用它的 ID 指定时仍然可以访问。旧版本的 Wisp Study 打开同一个数据目录时，会把这些对话当作普通文献库列出。

要把一个文献库交给另一台电脑上的 Wisp Study，在首页文献库卡片的菜单里选「导出文献库」，或在文献库里点「导出」，选「整个文献库」。可以选含 PDF 或不含 PDF：不含时文件小得多，对方拿到文献、词条、筛选、笔记、对话、稿件和图片库，但没有全文，PDF 上的标注和已读出的全文也不带过去。导出的是一个 `.wispstudy` 文件（其实是 tar.gz 压缩包）。对方在首页点「导入文献库」选这个文件，或直接拖进窗口，就会新建一个文献库；同一个文件导入两次会得到两个库，同名的在名称后加编号，不会与已有的库合并。由更新版本导出的文件，需要先升级再导入。改名前的 Wisp Paper 导出的 `.wisppaper` 文件也可以这样导入。

## 收集

- 粘贴 DOI 或 PMID（或它们的链接）：从 Crossref 和 Europe PMC 查询题目、作者、期刊、卷、期、页码、年份、摘要。可以一次粘贴多个，一行一个或用空格分开：多个时对话框随即关上，在后台查询，进度和每一个的结果在左侧栏的「按 DOI / PMID 导入」里；已有的文献和认不出的词跳过，不耽误其余的。只粘贴一个时在对话框里等结果，没查到会说明原因。
- 粘贴网址：同一个对话框也认文献网页的网址（出版商的文章页、arXiv 的摘要页）和 PDF 本身的地址，可以和编号混在一起粘贴。网址在后台处理，结果和编号一起列在左侧栏的导入明细里。每个网址只用本机的网络打开一次：在校园网里、出版商按 IP 开放下载的，PDF 也能取到。网页上写着的 DOI 或 PMID 用来查询题目、作者等信息（库里已有的不会重复添加），再下载网页标出的 PDF；PDF 拿不到（付费墙、登录页、验证页、只是补充材料）时再找开放获取的版本。网页打不开、但网址里写着 DOI（如 `…/doi/10.1021/…`）时，照样按这个 DOI 添加。PDF 的地址按拖入的 PDF 处理。最后没有 PDF 的，记录照样保留，明细里写出原因，可以在浏览器里下载后把 PDF 拖进窗口，它会附到这一条上；既认不出编号也没有 PDF 的网址不添加。一个网址最多花两分钟：对方迟迟不回应时不再等下去，后面的网址接着处理；已经添加的文献保留，明细里写「花的时间太长」，缺的 PDF 之后可以用「查找开放全文」再找。不登录，不带 cookie，不冒充浏览器，也不跟随网页上 PDF 以外的链接。
- 拖入或选择 PDF：提取文字，在前两页找 DOI 并查询元数据；找不到 DOI 时以文件名建条目。同一个文件换了名字再拖进来，按文件内容认出是已有的那篇（在回收站里的也算），不会多出一条。
- 没有 DOI 的文献可以「按题目补全」（文献详情里的按钮）：题目取自文献本身，题目还是文件名时取自 PDF 首页（可以改），再到 Crossref、Europe PMC 和 arXiv 查找相近的记录。每个来源单独说明查到几条、没有查到还是没查成。候选列出题目、作者、年份、期刊和编号，标出与所查一致和不一致的地方；预印本和正式发表的版本是两条记录。点一条候选逐个字段核对：默认只勾选现在空着的字段和只是文件名的题目，已有的内容勾选后才替换；题目和所查不一样的记录不预先勾选任何字段。候选已是库里另一篇文献时不能写入。发出去的只有题目、作者和年份，不上传 PDF，不经过模型，也不打开浏览器抓取网页；一篇文献可以一直没有 DOI。
- 有 DOI 或 PMID、但缺期刊等信息的文献可以「按 DOI 补全」（没有 DOI 时是「按 PMID 补全」）：在右键菜单里，期刊、作者或年份空着时文献详情里也有这个按钮。按编号到 Crossref 和 Europe PMC 取这一条记录，同样逐个字段核对，默认只勾选空着的字段，已有的内容勾选后才替换。记录的题目和文献的不一样时（比如 PDF 首页印的是所引文献的 DOI）会提醒，并且不预先勾选任何字段。发出去的只有这个编号。
- 一次导入多个 PDF 时，侧栏下方有一块进度（已完成几个、正在读哪个文件），换到别的页面也看得到。读完后它变成一份汇总，直到你关掉：新增几篇、附到已有文献几篇、在回收站里所以没导入的几篇，以及还要处理的（没认出 DOI、待补全题目和作者的；没读出文字的）。点这一块打开明细，逐个文件列出结果和原因，点一行打开那篇文献。
- 导入 BibTeX / RIS；手动录入。
- 从 Zotero 6 / 7 本地数据库导入个人库与群组库的文献信息、标签、笔记和本地 PDF；分类路径转为标签。只读源库、复制附件，已有记录保留并补 PDF；进度和结果明细列出重复、回收站及失败原因。见 [Zotero 导入教程](ZOTERO.md)。
- 按 DOI、PMID、题目去重，重复导入不会产生重复条目。

## 整理

- 搜索（题目、作者、DOI、标签、词条、摘要、笔记）、筛选、排序。
- 阅读状态、收录判断、收藏、标签、笔记。
- **自定义词条**：每个文献库自己定义字段（文本 / 多值 / 单选），可填写、筛选、作为表格列。
- 「全文」一栏有四种状态：无全文、有链接、已存 PDF，以及「PDF 无文字」（存了 PDF 但没读出文字，全文暂时不能用于提问）。可以按它筛选。
- 回收站：删除的文献可恢复（一篇篇恢复，或「全部恢复」），并继续阻止同一篇被重复导入。「清空回收站」把里面的文献连同笔记、词条、标注、PDF 和图片从磁盘上彻底删除，无法恢复，要输入「我已知晓」才会执行；清空之后它们不再阻止重复导入。单篇的「彻底删除」同样是真删除，确认一次即可。移到回收站是后悔药，离开回收站就没有了。
- 导出 BibTeX、CSV（当前列表）。
- **命令面板**：按 `Ctrl` / `⌘` + `K` 打开，输入几个字找到要做的事或要找的文献：切换页面和视图、添加与导入、导出、打开别的文献库、切换外观、打开设置的某一页；输入题目、作者、标签或摘要里的词，直接打开文献库里的那篇文献。上下键选择，回车执行，Esc 关闭；中英文都能搜到命令。
- 侧边栏：拖动它右侧的分隔线改变宽度，宽度会记住；双击分隔线、点左上角的按钮或按 `Ctrl` / `⌘` + `B` 收起，把窗口让给列表和文献，再点按钮或按快捷键回来。拖到很窄也会收起。

## PDF 预览

在详情面板里直接看 PDF。渲染用纯 Rust 的 [hayro](https://github.com/LaurenzV/hayro)，不依赖系统 PDF 库。

- 正文与附件：文献详情的文件分成「正文 PDF」和「附件／补充材料」两块，各有自己的添加按钮。每个 PDF 文件行都有「阅读」，附件也能在内置阅读器里打开，缩放、高亮、方框、便签都可以用。阅读器工具栏左侧写着正在读的文件（「正文 · …」或「附件 S1 · …」），点它切换到正文或其他附件；每个文件各自记住读到的位置，标注也各归各的文件。
- 就这篇文献提问时，正文和全部 PDF 附件一起交给助手，对话上方列出已纳入的文件。回答引用附件时写成 `[P1 S1 p.2 "…"]`（S1 是第一个附件，页码是附件自己的），出处卡片写明附件编号和文件名；点击会打开那个附件并高亮这句原文。

- 表格列：拖动表头里两列之间的分隔线改变列宽，宽度会记住，双击分隔线恢复这一列的默认宽度。右键表头选择显示哪些列（期刊、年份、全文、阅读、收录和各个自定义词条），也可以一次恢复默认列宽。窗口不够宽时，放不下的列先让出位置，「文献」这一列的表头末尾会出现「+N 列」：鼠标停在上面说是哪几列，点它选择显示哪些列；拉宽窗口或收起侧栏，它们就回来。放不下的题目、期刊和词条以「…」结尾，鼠标停在上面显示完整内容（题目的提示里还有作者、年份、期刊和全部标签）。
- 表格列：拖动表头里两列之间的分隔线改变列宽，宽度会记住，双击分隔线恢复这一列的默认宽度。右键表头选择显示哪些列（期刊、年份、全文、阅读、收录和各个自定义词条），也可以一次恢复默认列宽。放不下的题目、期刊和词条以「…」结尾，鼠标停在上面显示完整内容（题目的提示里还有作者、年份、期刊和全部标签）。
- 面板宽度：拖动文献列表和详情之间的分隔线，宽度会记住；双击分隔线恢复默认。右上角的展开按钮仍然一键让出阅读宽度。
- 阅读模式：PDF 工具栏上的「阅读模式」（`Ctrl` / `⌘` + `Shift` + `F`，可改键）收起侧边栏和文献列表，整个窗口留给这篇文献，顶上只剩题目、三个标签页和「退出阅读」；`Esc` 退出。进出阅读模式，PDF 停在原来读到的地方，对话和没发出的问题也都还在。
- 查找：PDF 有键盘焦点时（点一下页面）按 `Ctrl` / `⌘` + `F`，左上角出现查找栏，在整份 PDF 里找输入的词（不分大小写，跨行、连字符断开的词也找得到），找到的地方标出底色；`Enter` 或箭头逐处跳转，`Esc` 收起。在 PDF 里选中了文字时先填上它。
- 引文对不上时自己找：点引用、出处跳到 PDF 时，那句原文可能是改写、翻译过的，或被排版拆开了，没能逐字对上。这时提示旁有「自己搜索」：打开查找栏，先用句中较长的词（术语、名称）逐个去找，直到有一个在 PDF 里找到；也可以换成句中别的词、数字或术语自己找。
- 缩放：工具栏上有缩小、当前比例、放大，旁边一个方框图标是「适应整页」：无论正在适应宽度还是手动缩放，点一下就让当前这一页上下左右整页显示，并把这一页的顶端对齐到阅读区（已在整页时再点一下，回到这一页的开头）；点比例可选「适应宽度」「适应整页」或 50% 到 400%。`Ctrl` / `⌘` 加 `+`、`-`、`0` 是放大、缩小、适应宽度（可在「设置 › 快捷键」里改），`Ctrl` / `⌘` 加滚轮以指针位置为中心缩放；在触控板上双指捏合也一样，张开放大、捏拢缩小。页面比面板宽时，面板底部会出现一条横向滚动条：拖动滑块或点滑块两侧就能左右移动，也可以双指横向滑动，或按住 Shift 滚动。
- 自动适配：打开文献默认「适应宽度」。在「适应宽度」或「适应整页」下，最大化或调整窗口、展开或收起侧栏、拖动面板或对话的分隔线、进出阅读模式时，页面跟着可用的宽度变化，停在正在读的那一页、那一处。选过的适应方式会带到下一篇；为看图表手动调的百分比只属于这一篇，换一篇时回到适应方式。手动缩放后，若你读的是「适应宽度」，比例旁边会出现「适应宽度」，点一下就回去（读的是「适应整页」时，点方框图标即可）。
- 分屏：工具栏的「分屏」可选「左右分屏」或「上下分屏」，同一份 PDF 分成两半显示，各自滚动、翻页：图在一页、说明在另一页时，一半停在图上，另一半去读说明。两半大小相同，缩放和适应方式一起变；选字、标注、截图、翻译在哪一半都可以用，高亮和下划线两半都看得到。页码、左右方向键翻页和从回答跳到的引用，跟着你最后点过或滚动过的那一半。选「不分屏」收起时留下最后操作的那一半的位置。分屏只属于当前这一篇，换一篇时回到不分屏；阅读模式内外都可以用。
- 选字：在页面上拖动选中文字（限于一页之内），双击选中一个完整的词（不带两侧的空格和标点，`Single-cell` 这样带连字符的算一个词），`Ctrl` / `⌘` + `C` 复制，或用选区下方的「复制」「添加到对话」。没有文字层的 PDF 选不了字。
- 标注：选中文字后点「下划线」或「高亮」（新高亮是黄色）。点一下已有的高亮，旁边出现一个小菜单：选一种颜色（黄、绿、蓝、粉、紫、红、橙，当前的那个带圈）就把这条高亮换成这个颜色，范围不变；「删除高亮」只删掉点中的这一条。两条高亮叠在一起时，点中的是后加的那条。在高亮上拖动仍是选中文字；按 Esc 或点别处收起菜单。右上角「标注」列出当前 PDF 的所有标注，可以定位原文、编辑笔记或删除。标注单独存入文献库数据库，在阅读器中按页面坐标叠加显示，缩放和重新打开后仍保留；原始 PDF 文件不变，用外部阅读器打开原文件时不会显示这些标注。标注绑定具体附件，移除附件时同时移除；文献进入回收站时保留，恢复后可继续查看。内置助手、CLI 和 MCP 可通过 `list_pdf_annotations` 读取原文、笔记、类型、高亮颜色、页码和位置；用户笔记与论文原文分开提供。
- 方框：工具栏的「方框」之后，在页面上拖出一个矩形，框住一张图、图中的一块或一段文字；框是空心的，框里的内容照样看得清。可以连续画几个，再点一下「方框」或按 Esc 回到选字。点方框的边打开菜单：换颜色（默认红色）或「删除方框」；选中后拖动边框移动，拖四个角改变大小。图表、文字和扫描页都能用。
- 便签：工具栏的「便签」之后，点页面上任意位置（文字旁、图上、页边留白、扫描页都可以），那里出现一张便签卡片，写下想法后「保存」。便签平时收起成一个小图标，点一下展开，可以「编辑」或「删除」；按住图标拖动可以换位置。卡片尽量放在页面两侧的空白处，不挡正在读的正文。方框和便签与高亮一样按页面坐标保存，缩放、翻页、重新打开后仍在原处，也列在右上角「标注」里。
- 截图：工具栏的「截图」之后，在页面上框出一块（一张图、一个表格）。框好后可以「收藏到图片库」，或者「用这张截图提问」：它会作为图片加到提问的输入框上方。
- 页面先出一张粗图，随即换成按显示大小渲染的清晰图；单页图像有上限（约 2400 万像素），在高分屏上放大到 300% 以上会略微变软。

## 图片库

从文献的 PDF 里截下来的图和表，收在左侧「收藏」里：「收藏」上面有「文献 / 图片」两个切换，星标的文献和收藏的图片各占一边。

- 收藏：在 PDF 工具栏点「截图」，在页面上框出一张图或一个表，点「收藏到图片库」。弹出的对话框里是这张截图和四个字段：图号、图注、标签、备注。图号和图注会从这一页的文字里读出来（认 `Fig. 2 | …`、`Figure 3.`、`Table 1`、`Extended Data Fig. 4`、`图 3` 这些写法；图的图注在它下面找，表的在它上面找），收藏前看一眼、改掉不对的地方。收藏后仍然留在截图状态，可以接着框下一张。
- 让模型来写：图注、标签、备注三个字段名的右边各有一个 AI 图标。点一下，提问用的模型会看着这张图写出这一项：图注（截图里看得到图号时连同图号，只填进空着的图号栏；图注在另一页、截图里没有图号时，图号要自己填）、3 到 5 个标签（优先用图片库里已有的）、两到四句解读。写出来的内容在字段里，可以改，也可以撤销；和别的字段一样，点「收藏」或「保存」才会存下来。图片会发给模型服务。
- 标签：图片有自己的标签，和文献的标签分开，适合按图的类型和用途来分（配色、UMAP、示意图……）。对话框里列出已有的标签，点一下就加上。
- 浏览：卡片上是缩略图、图号、图注、出处和标签。可以搜索图注、图号、标签、备注，以及所属文献的题目、作者、期刊和年份；点一个标签只看带它的图片。
- 回到原文：点开一张图片，「打开原文」会在右侧打开它所在的 PDF，并滚到截图的位置；「用这张图提问」把它带进这篇文献的对话；还可以复制图片、另存为文件。卡片上点右键也有这些操作。
- 文献进了回收站，它的图片暂时不显示，恢复后回来；文献从回收站彻底删除时，图片文件跟着从磁盘删除。单独移出图片库的图片不会被删除，而是移到文献库文件夹下的 `removed` 文件夹。
- 图片文件在文献库文件夹的 `figures` 里，和数据库、PDF 一起备份、拷走。命令行和 MCP 的 `list_figures` 可以查询它们。

## 全文的文字

提问、检索全文和写作页用的是从 PDF 里读出的文字。

- 读取：先按字形的位置读（保留页面上的分段），不行再换另一种读取方式。两种都读不出时，文件照样保存，但状态是「PDF 无文字」。
- 原因分开说：文件打不开、设了打开密码、两种方式都解析不了（不代表它是扫描件）、字体没有给出文字编码、页面上没有文字层。助手得到的也是同一句原因，并被要求照此转述，不去猜文件是不是扫描件或加了密。
- 在文献详情的「文件」里可以看到每个文件读出了几页文字；没读出的，下面写着原因和两个按钮：「重新读取」，以及「让模型读页面」（把页面作为图片交给能看图的模型，读出的文字按页保存，并记下是哪个模型读的；需要在「设置 › AI」里配置模型）。
- 在「助手」里向文献库提问时，顶部的范围说明会写出其中有几篇的 PDF 没读出文字。
- 文件一行会写出有文字的页数（「15 页中 14 页有文字」）；由查找得来的文件还会写出来源和版本。

## 查找开放全文

检索导入的文献大多只有记录，没有 PDF。「缺 PDF」视图顶部的按钮可以替这些文献找开放获取的全文，下载后附到原来的条目上，并读出文字；单篇文献在「PDF」标签里也有「查找开放全文」。

- 只找可以免费合法获取的版本：arXiv；OpenAlex 和 Europe PMC 列出的开放获取文件；以及被这两个索引标为开放获取的 Springer / BMC、Nature、Frontiers 文章在出版商那里的 PDF。不登录，不绕过付费墙，找不到就说没有。
- 查找时会把文献的 DOI 或 PMID 发给 OpenAlex、Europe PMC 和出版商；没有 DOI、PMID 或 arXiv 编号的文献查不了。
- 侧栏下方显示可点击的分段进度条：绿色为已保存，黄色为未找到地址，红色为下载失败，蓝色为正在查找，灰色为等待处理。点击打开实时详情，查看正在处理的论文、逐篇结果和失败原因；收起弹窗后继续查找，完成后仍可重新打开。
- 详情中可以停止查找：不再开始下一篇，已经发出的请求完成后仍会记入结果。保留本次总数，并显示未处理的数量。「未找到地址」仅表示本次未检索到候选 PDF 地址，不代表论文一定没有开放全文。取回来的不是 PDF（登录页、验证页）不会被存成 PDF；取回来的是论文的补充材料（开头几页只有附图、附表及其图注）也不会当作全文保存，接着试下一个地址，都不行就在失败原因里写明。
- PDF／文件夹导入和 Zotero 导入使用相同的侧栏进度条与实时详情弹窗。绿色为已导入，黄色为需要完善信息或附件，红色为导入失败，蓝色为处理中，灰色区分已跳过与等待中。PDF 导入详情会列出正在读取的文件；收起后继续导入。
- 没有取到的，打开文献的链接自己下载，再把 PDF 拖进窗口，它会按 DOI 附到原条目上。
- 同一件事也是一个工具 `find_pdf`：`wisp find_pdf`、MCP 和窗口里的助手都能用；助手用之前会先问你。

## 建库向导

- 新建文献库后先问从哪里开始：从检索文献开始、导入已有的文献，或者先空着。
- 从检索开始：写下主题或关键词，助手为所选的数据库各拟几条取向不同的检索式，并逐条试检索；你按命中的文献选出靠谱的，保存并导入。已有的文献库也可以从「检索与导入」页进入。

## 检索与导入

- 为 PubMed、Europe PMC、Crossref、arXiv 保存检索式；「试检索」显示数据库命中总数和最新的记录，并标出哪些已在库中。
- 「运行并导入」把新文献加入文献库（都是「待判断」），已有的跳过；每次导入可以整批撤销：处理过的文献（做过收录判断、读过、收藏、写过笔记、加过标签或附件、提过问、被稿件引用）保留；没动过的移出文献库，不进回收站，所以以后的检索还能再把它们导入。移出的记录另存为文献库文件夹里的 `removed/undone-import-<批次号>.bib`，需要时可以用「导入 BibTeX / RIS」再导入。
- 一条检索式每次最多取回最新的 2000 篇（在检索式里设置，默认 50）。多于 200 篇时分几次向数据库要；中途断了，已经取回的照样导入，记录里写明在哪里中断，一小时内自动重试。第一次运行取全，之后的运行只取库里还没有的：PubMed 只下载库里没有的记录，其他数据库在一页里没有新文献、命中总数也没有多出来时就停下。
- 自动更新（默认关闭）：每 6 小时、每天或每周运行已启用的检索式。应用开着时每分钟检查一次；关着时错过的，下次打开时补上；失败的最多一小时后重试。不开窗口时可以让系统的计划任务定期执行 `wisp sync_searches`（见[命令行与 MCP](CLI.md)）。

## 筛选

- 「筛选」页列出待判断的文献。助手阅读每一篇（有全文读全文，否则读摘要），给出建议、理由、一句逐字引自原文的依据和把握；引文不在原文里的不会被当作依据。
- 批量进行：几篇同时读（1 到 8 篇，在「设置 › AI」里定），页面上有进度条和正在读的文献。个别文献没判断成不会打断这一轮，连续三篇失败才停下；没判断成的留到下一轮。
- 判断完的队列按助手的建议分组（已纳入、相关、证据不足、不相关、还没有建议），可以只看其中一组。
- 建议只是建议：每一篇的收录判断由你确认，可以采纳，也可以另选；看过一组之后，也可以把整组按建议一次采纳（会先问一遍）。外部 agent 通过 MCP 或命令行只能提建议。
- 在「确认」里一起过目时，助手什么都没读到的文献（没有摘要，也没有全文）默认不勾选，留在待判断：这种「证据不足」只说明没有东西可读，不是判断的依据。要写入就自己勾上，或给它另选一个结论。
- 一轮一轮收紧：筛完之后，在「筛选目标」里写一个更严的目标，点「在已纳入的 N 篇里继续筛」，助手只读已纳入的文献；它看法不同的回到队列，在「确认」里和其他建议一起写入，每行写着「原判断」。也可以「复核已判断的 N 篇」，范围是所有判断过的文献。
- 每一轮（一个筛选目标下助手的第一次批量判断开始一轮）都记下当时的数字：筛选目标下面一行写着「第 3 轮 · 540 → 100 → 23 篇已纳入」，悬停看每一轮的日期、目标和进出数字。只靠手动判断、没让助手读过的轮次不记录。
- 队列判断完后，「把未纳入的 N 篇移到回收站…」把相关、证据不足和不相关的文献一次移进回收站（先问一遍，列出各有几篇），可以从回收站恢复。

## 提取

- 让助手替你填自定义词条：它逐篇阅读（有全文读全文，否则读摘要），为每个词条提出取值，并摘一句逐字引自原文的依据；引文不在原文里的不会被当作依据。文中没有说明的，它就答没有，不猜。
- 从三处开始：在文献列表里选中几篇，右键「让助手填写词条…」；在「自定义词条」里点「让助手填写…」，范围是当前列表；或在一篇文献详情的词条旁点 ✦，只问那一项。开始前选要问哪些词条，对话框会说要读几篇、几篇有全文。已经填好或已经问过的不会重复问，除非勾选「重新提取」。
- 词条可以带一句说明（「自定义词条」里填），告诉助手要找什么，例如“研究用的物种，写学名”。「要点」是现成的一个：一两句话概括这篇文献发现了什么，没有时对话框里可以一键添加，它就是一个普通的文本词条，也可以作为表格的一列。
- 几篇同时读（篇数和模型与筛选相同，在「设置 › AI」里定），侧栏和「提取」页上有进度，可以随时停止。个别文献没读成不会打断这一轮，连续三篇失败才停下；没有摘要也没有全文的文献不会去问。
- 一轮停下之后（连续失败、你点了停止，或个别文献没读成），进度栏上有「选模型重试」：从列出的模型里选一个，把这一轮没读成和没轮到的文献按同样的词条再读一遍。选的模型只用于这一次，不改「设置 › AI」。读的时候，进度栏左边的箭头可以把正在读的文献列表收起。
- 「提取」页列出等你确认的取值，一行是一篇文献的一个词条：取值、原文里的那句话（有页码时点击打开 PDF 并高亮这句）、出自哪篇文献。可以只看某一个词条。默认勾选的是词条还空着、且找到了原文依据的取值；词条已有别的值的、没有原文依据的不勾选，留给你判断。
- 单选词条的取值只能是它的选项之一：助手的回答对不上任何选项时不会写入，那一行列出选项让你选，或者留着不写。多值词条写入时保留已有的值，新的加在后面。
- 「写入」把勾选的取值一次写进词条（要么全部写入，要么都不写），写入之后可以撤销；用不上的可以「清除」，清除的不再列出，也不会再问。写入之前什么都不会改动。
- 写入之后，这句原文留在文献详情里那个词条的下面：以后看到一个取值，可以点回它的出处。
- 外部 agent 通过 MCP 或命令行的 `suggest_field` 只能提出取值，同样出现在这里等你确认。

## 写作：导入已有的稿件，带批注审阅

- 稿件可以从零开始写，也可以从已有的文件开始：写作页「稿件」菜单里的「导入 Word / Markdown 文件…」，或者把 .docx 拖进窗口（在写作页上，.md 和 .txt 也可以）。标题变成各节；没有用标题样式的 Word 文件，按「摘要」「引言」「方法」这类常见的节名分节。
- 助手在对话里写的东西也能接着改：综述记录写好的各节，在「稿件」菜单里是「从助手的综述新建」（对话里也有「存为新稿件」）；一条回答可以「保存为新稿件」或「插入到稿件」。
- Word 文件里合作者留的批注一并读入，显示在右侧的「批注」页（和「候选句」并排的另一页）；被批注的文字在稿件里有底色，点批注上的引文回到那处文字。来自 Word 的批注只能标为已处理，不会从文件里删掉。
- 「让助手审阅这一节」（选中文字时只审阅选中的部分，可以先写一句想让它看什么）：助手像在 Word 的审阅模式里那样留批注，每条指向一处原文；需要改文字的带着「建议改为」，并优先回应合作者的批注。只有你点「采纳修改」才会改稿件：批注随之落在改后的文字上，保留原文，可以「撤回修改」。也可以「采纳全部」。再审一次会替换上一轮还没处理的批注。
- 选中文字后，段落操作在选区旁的浮动菜单里出现，分成三组：「找句子」「配引用」只在文献库里查找，不改文字；「润色」「译成…」「仿写」和你自己的命令给出改后的文字，由你决定是否替换；最后是「批注」。每个按钮悬停时说明它会给出什么。菜单随滚动定位，按 Esc 或点击外部收起。没有选中文字时，稿件下方仍保留当前段落的操作。
- 「仿写」参照文献库里与这段最相近的句子改写：右边的候选句不是为这段找的时候，它先找一遍再改写；借鉴的是结构和措辞，意思以你写的为准，用到某篇文献的发现时补上 `[@Key]`。
- 在来自 Word 的稿件里，用「润色」「仿写」「译成…」替换一段、或用「配引用」加了引用之后，那一段上自动留一条助手的批注（做了什么、原文是什么）。
- 导出为 Word：来自 Word 的稿件写回原文件，没改的段落原样保留（版式、表格、图片、脚注、域代码都在原处），改过的段落只在原有的格式片段里改字；批注写成 Word 自己的批注。可以选「改动记为修订」，对方在 Word 里逐条接受或拒绝。从零写的稿件导出时同样带上批注。署名在「设置 › 通用 › 写作」。
- 导出的 Word 文件按期刊的格式写引用，文末列出参考文献（稿件里仍是 `[@Key]`）。引用是 Word 的域：点正文里的 `[1]` 或 `(Zhang et al., 2024)`（Word 里是 Ctrl / ⌘ 加点击）跳到文末对应的那一条。格式在「导出」菜单下方选：两种简单格式（作者-年份、编号），常用的期刊样式（APA、Nature、Cell、Vancouver、IEEE、GB/T 7714—2015 顺序编码和著者-出版年、Chicago 著者-年份），以及你自己添加的样式。
- 引用样式用的是 CSL，与 Zotero 相同的定义文件：从 Zotero 样式库下载的 `.csl` 用「添加引用样式文件（Zotero 的 .csl）…」加进来就能选；本机 Zotero 里已安装的样式也会直接列出。只是某个样式别名的文件（很多期刊如此）需要它所指的那个样式也在；脚注式的样式不支持。条目里的卷、期、页码取自文献记录：从 Crossref、Europe PMC、PubMed、BibTeX / RIS、Zotero 来的记录会带上，以前导入的文献这三项是空的，可以在「编辑文献」里填，或用「按题目补全」补上；空着的项样式会略过。
- 想要的格式没有现成的，可以让助手改：在对话里说清要求（例如「在 Nature 的基础上，把上标改成方括号，题目加粗」），助手读出最接近的样式、改它的 CSL、用库里的文献试排给你看，认可后存成你的样式，出现在「导出」菜单里由你选用。
- 表格和图片不进稿件的文字，留在 Word 文件里；Word 里未接受的修订按接受后的文字读入。

## 写作：让助手来写

写作页有两种方式，在大纲上方（大纲收起时在稿件上方）切换，同一份稿件随时可以换：

- **自己写**：你动笔。右边是候选句、批注和参考文献，稿件下方可以让助手按你的话改这一节。
- 在写作页按 `Ctrl` / `⌘` + `F` 是在稿件里查找，不再跳去搜索文献：稿件上方出现查找栏（选中了一小段文字时先填上它），这一节里找到的地方标出底色，光标之后的第一处被选中；`Enter` 或箭头去下一处、上一处，下一处在别的节时自动翻到那一节，在「预览」里也一样会回到那一节。`Esc` 收起查找栏，光标停在找到的地方。两种方式下都可用。`Ctrl` / `⌘` + `Shift` + `F` 在写作页切换稿件的「预览」（旁边开着文献时仍是那篇文献的阅读模式）。
- **助手写**：左边仍是大纲，中间是和助手的对话，右边是稿件。交代要写什么、改什么，助手自己在文献库里找文献和原句、读全文，然后直接写进稿件：写一节的初稿、逐处修改、拟定或调整大纲、改题目和正文语言。它在对话里只说做了什么、依据哪些文献、还缺什么，正文在右边看。

助手写的时候：

- 助手每次动笔前，那一节原来的文字都留一个版本。稿件上方的「版本 2/3」左右翻看这一节的各个版本，早先的一版可以「恢复这一版」（恢复前的文字也会留一版），或「回到现在」。
- 助手改过的地方在稿件里有底色，左边缘有一条竖线；大纲里刚改过的节有一个圆点。稿件下方列出这一节的每处改动，点一下定位，可以单独「撤销」或「全部撤销」，「保留」后标记消失。改动不在当前这一节时，右边会跟到它改的那一节。
- 稿件始终可以亲手改；选中一段文字再对助手说话，它知道你指的是这一段。
- 助手写进稿件的引用是稿件的格式 `[@Key]`；它引用时摘出的原句，在文献里确实找得到的会记为这处引用的出处（参考文献页和稿件下方可以点开核对），找不到的会被告知并要求改正。
- 对话按稿件保存：换一份稿件就是那份稿件的对话，「历史」里是这份稿件的历次对话。
- 大纲调整时，没写过内容的节会按助手的大纲去掉，写过内容的节不会被删除。
- 这种方式下没有候选句面板，查找候选句的快捷键不起作用；需要时切回「自己写」。

在「助手」页（整个文献库的对话）里，助手同样可以改稿件，但每次都会先列出要改哪一节、改几处，等你同意。

## 翻译

- 文献详情的「摘要」旁有「显示译文」：题目和摘要在原位置换成译文。打开以后，之后点开的每一篇都会翻译，直到点「显示原文」。
- 译过的文字保存在文献库里，同一段文字不会请求第二次。翻译的要求（目标语言、术语、格式）可以在「设置 › AI」里改；改了以后按新的要求重新翻译。

## 助手与提问

- 左侧的「助手」是和整个文献库的对话：可以提问，也可以交代一件事（试检索外部数据库、运行检索式导入、查找开放全文、提出筛选建议、分阶段写综述）。开始对话前，页面按「找文献、读文献、整理、写」列出它能做的事：点一句话就发出去，点一个命令则把它放进输入框，等你写上后面的内容。
- 助手可以替你整理文献：加或去标签、设星标、改阅读状态、往「我的笔记」末尾追加一段（注明是助手所记，不覆盖已有内容）。它动手之前，对话里会列出每一篇要改什么，等你同意；同意后一次写入，其中一篇有问题就一篇都不写。收录判断和自定义词条不在其中：前者它只能在筛选页提建议，后者在提取页提建议。
- 给写好的 Word 文件换引用格式：把一个 `.docx` 拖到「助手」页（或点输入框左边的「+」选它），它作为一个小标签附在问题上，然后说要什么样式，例如「改成 Nature 的格式」「用 GB/T 7714，顺序编码」「Nature 但编号用方括号」。助手先读出文件引用了什么并告诉你：文件带 Zotero / Mendeley 的引用域时，文献信息直接取自域，不用猜；否则按文字识别「参考文献」/ References 后面的条目和正文里的 [1]、[2, 4–6]、上标编号或（Zhang et al., 2024; 张三等，2020）这样的引用，条目先和文献库里的文献对（DOI、PMID、题目），对不上的按条目自己的文字读，还可以让它联网查 Crossref。确认后助手输出一个新文件，保存位置由你在对话框里选：正文里的引用就地换成新样式，每一处都是点了能跳到参考文献表对应条目的域，参考文献表整个换成新样式，其余内容、格式、图表、批注不动；也可以让它把改动写成修订。原文件不会改动，已有的文件不会被覆盖。没能识别的条目原样留在表末，引用它们的地方、带「参见」之类前缀的引用保持原样，助手会逐条说明。引用样式和写作页导出用的是同一套 CSL，改样式的办法也一样（见上）。Zotero / EndNote 的引用域重排后是普通的跳转域，之后要增删引用请在原文件里改好再重排一次。
- 把写好的稿件交给写作页，也可以在「助手」页说：附上 `.docx`（或给出 `.md`、`.txt` 文件的路径），说「把这个稿件添加到写作」。助手先列出会分成哪几节、带进来几条批注，等你同意；导入后和在写作页「导入」的一样（原文件不动，同一个文件不会导入两份），写作页原来空着的「未命名稿件」让位给它。之后可以接着让助手读它、给它留批注。
- 助手可以读你在写作页的稿件，所以能就稿件提意见，或按稿件已有的内容接着写；要它直接改稿件时，会先列出要改什么、等你同意（在写作页的「助手写」里不用逐次同意，见上）。回答下面的「插入到稿件」把这条回答加到你选的那一节末尾，选中一段时是选区旁的「所选插入稿件」；`[P3 p.5 "…"]` 这样的引用变成稿件用的 `[@Key, p. 5]`，那一节原来的内容先留一份历史版本。
- 写作页的段落操作里有「配引用」：为选中的文字（或光标所在的段落）逐句找文献库里可以引用的文献。它不改写文字，结果是一张清单：每句话下面列出找到的文献、模型认为它贴切的理由，以及这篇文献自己的一句原文（全文里的带页码，点右上角的图标在 PDF 里看这句）。模型核对后认为可以引用的已经勾好，其余相近的收在「还有 N 篇相近的」里，可以自己改选；点「插入 N 条引用」才把 `[@Key]` 加到各句句末，可以撤销。稿件用中文写、文献是英文的也能找：翻译用的模型先把每句话变成文献那种语言的检索词。没有配置模型时，列出按用词找到的相近文献，不勾选，由你判断。
- 引用带着出处：右边「参考文献」页里，每篇文献下面是引用它的那句话所依据的文献原文，附所在的部分和页码，点一下就在 PDF 里翻到那一页并高亮这句。光标停在稿件的一处引用上，稿件下方会出现一行：这是哪篇文献、这句话依据的是它的哪句原文；参考文献页同时滚到那篇文献并标出这条出处。出处在引用时记下：在候选句上点「引用」、在「配引用」里勾选插入、把助手的回答（它引的原句）插入稿件。已经写好的引用可以事后找：点参考文献列表上方带数字的星标（或光标所在引用那一行的星标），助手到每篇被引的文献里检索，再由模型核对哪一句是依据；核对后认为文献里没有依据的，会在那篇文献下面用提醒色标出，方便检查引错的地方。出处只记在文献库里，稿件的文字仍是 `[@Key]`；句子改写后仍按内容对得上，不要的出处可以点 × 去掉。
- 向文献库提问：范围是当前列表（受视图、搜索、筛选影响），模型读到每篇的记录、笔记，以及已存 PDF 中与问题相关的页面。顶部的「文献」展开这些文献的列表：提问前是当前列表，提问后带上这次对话里的编号（P1、P2…）、每篇交给模型的是完整记录还是只有题目、给了几页全文、全文是否可读。点一行在右侧打开那篇文献，对话不动，范围也不变。
- 就单篇文献提问：模型读到该文献的记录和全文。点「提问」后窗口换成提问的布局：侧栏收起，文献成为左边一条窄列表（带搜索，↑↓ 换一篇），中间是对话，右边是这篇的 PDF，边读边问。没有 PDF 的文献布局不变，右边是「添加 PDF」和「查找开放全文」。按 Esc、点「退出提问」或切回「信息」就回到完整列表；点 PDF 工具栏右端的 × 收起 PDF，之后提问只在右侧面板里进行，点「对照 PDF」再展开。窄列表与对话、对话与 PDF 之间的分隔线都可以拖动，宽度会记住，双击恢复默认。习惯左边看论文、右边提问的，点标题行右端的 ⇄ 把 PDF 换到左边，再点一次换回来；换的时候 PDF 停在原来的页和缩放，对话和还没发出的问题都在，这个选择对之后的每篇文献和重启后都有效。
- 在 PDF 上选中的原文可以「添加到对话」：它带着页码出现在输入框上方，提问时作为引文交给模型，回答引用它时可以原路跳回那一页。文献库的对话和这篇文献的对话同时可见时，可以选加到哪一个。也可以把页面上框出的一块作为图片提问。
- 材料不够时，助手会自己调用工具在整个文献库里检索全文、按页翻阅、查询记录。一轮调用收成一行（「检索全文 ×2 · 阅读全文」），点开看每次调用和结果；只读的调用并行执行。
- 助手要运行检索式导入文献、撤销导入或删除检索式时，会先停下来等你同意：允许这一次、这次对话里都允许，或者不允许。
- 回答过程中可以随时停止；已经写出的部分留在对话里，可以接着问。模型服务繁忙或连接失败时自动重试两次。
- 提问可以带图片（最多 8 张）：直接粘贴截图，或点输入框左边的「+」选择文件。过大的图片会先缩小，TIFF、BMP 会转成 PNG。所选的模型需要支持图片输入。
- 回答按 Markdown 排版：标题、加粗和斜体、列表、表格、引用、代码块，链接可以点开。
- 助手引的原句会和文献库里保存的那一页文字逐字比对（只比字母和数字，换行和连字符不算），结果写在出处卡片上：「原文一致」、「原文在 p.N」（助手给的页码不对，这句话在第 N 页，点击会去那一页）、「只对上开头的 N%」、「原文里没有这句」、「没有全文可核对」。这只说明这句话在不在原文里；它是否足以支持论断，由你判断。`/verify` 让助手把上一个回答逐条列成「论断、原文摘录、支持到什么程度」，摘录照样经过这道比对。
- 回答里的文字可以拖动选中（跨段、表格里也可以），双击选中一个词（规则和 PDF 里一样；中文选中两侧标点之间的一串），`Ctrl` / `⌘` + `C` 复制。松开鼠标后选区旁出现一条小工具栏：「引用追问」把选中的话作为引用块放进输入框（输入框里已经写的保留），光标停在后面，接着写你的问题；「复制」同快捷键。已有稿件时、在综述的对话里，选区旁还有把所选插入稿件、记进综述的按钮。工具栏随回答滚动，靠近对话上下边时换到选区的另一侧；点别处或按 Esc 选区和工具栏一起消失。右键菜单里是同样的「引用追问」「复制」。
- 鼠标停在你的提问上，下面出现「复制」和「撤回」：撤回把这个问题和之后的对话撤下，原话和图片回到输入框（框里正在写的接在后面），改了可以再发，这也是改问题的办法；发出下一个问题之前，对话末尾的「恢复」能把撤下的放回去。回答下面除了「复制」，最后一条有「重新回答」（用同一个问题再问一次，换掉这条回答），每条都有「从这里分支」：到这条回答为止另开一个对话接着问，原对话完整留在「历史」里。撤回和重新回答只改对话，助手已经对文献库做的改动不会跟着撤销。综述的对话不能分支。
- 回答正文里的 `[P3 p.5 "…"]` 和回答下面的出处卡片都可以点击：打开这篇文献的 PDF 并跳到所引的页；助手引了原句时，这句话会在页面上高亮（那一页没有就在全文里找，找不到会明说，并可点「自己搜索」用句中的词在 PDF 里查找）。筛选建议里的原文依据同样可以点击。
- 一个回答引了很多文献时，下面先列出前 8 个出处，其余的点「另外 N 个出处」展开。
- 输入 `/` 弹出命令列表，继续输入（英文名或中文说明里的字）筛选，↑↓ 选择，Enter 或 Tab 确认：`/search 词语` 在全文和记录里检索；`/cite 一段文字` 为这段文字逐句从库里找可以引用的文献；`/review 主题` 分阶段撰写综述；`/compare P1 P3` 比较几篇文献的方法和结论；`/write 部分 要写的意思` 从文献库里找这一部分的候选句来写一段；`/verify` 逐条核对上一个回答（或后面写的内容）的依据；`/new` 开始新对话。
- 常用的提问可以存成自己的命令（设置 › AI › 命令）：起一个名称，写一句说明和一段模板，例如 `/style-check` 检查空泛、重复的表达。模板里的 `{}` 换成命令后面写的内容；不写 `{}` 的模板可以单独使用。自己的命令和内置命令一起出现在列表里，标着「自定义」，选中后不会自动发送。它只是一段提示：不运行脚本，不增加工具，也不绕过确认。对话里保存着当时实际发出的内容，以后修改或删除命令，不会改变旧对话问过什么。
- 支持 Claude API、OpenAI 兼容的 chat/completions 和 OpenAI 的 Responses 接口。
- 单篇提问里，每条回答下面有「存为笔记」：先给你看一遍、可以改，确认后加到这篇文献「我的笔记」的末尾，不覆盖已有内容。对话里的 `[P1 p.5 "…"]` 会去掉只在这次对话里有意义的编号，页码和摘录保留；末尾注明这是模型的回答、没有核对原文。笔记本来就随文献记录一起提供给以后的提问。
- 对话保存在文献库里。没有配置模型时也能看历史对话，只是不能接着问；点「新对话」后会提示上一段已保存。点「历史」列出向文献库（或向这篇文献）提过的问题，点开一次对话可以接着问：模型会按文献库现在的内容重新读材料，以前回答里的 `[P3]` 仍然指向原来那篇文献。历史对话可以逐条删除。
- `/review` 让这次对话带上一份综述记录：写作要求、初步框架和大纲由你分别确认，大纲确认后一节一节保存正文，最后记下检查。初步框架来自已有综述（它们各问什么、怎么组织、哪里没讲到），大纲再对照它、按文献库里的研究重建；没有可参照的综述可以跳过这一步。对话上方是四步的进度，该你做的那一步在对话末尾的卡片里：采用最后这条回答（点一次就是记下并确认），或者发出要下一步内容的请求；也可以只采用回答里选中的一段。「查看记录」里每一项都能直接编辑，改过的在那里重新确认。记录保存在文献库，从历史对话可以接着写；已保存的正文按顺序存为新稿件，对话里的引用转成写作页的引用。完整操作见[分阶段撰写综述](TUTORIAL.md#9-分阶段撰写综述)。
- 保存一节正文时，它的每处引用成为一条证据：论断是引用所在的句子，来源是文献和页码，摘录的原句已和文献的文字比对。来源是否支持论断由你判断（支持、部分支持、不支持、无法判断）；句子或来源的内容变了，判断收回或标为待重新判断。没有引用的句子也可以手动记下依据。

## 设置

单独的设置页（首页或文献库侧栏的「设置」，默认 `Ctrl` / `⌘` + `,`），改动即时保存。

- **通用**：数据目录；启动时回到上次的界面（上次离开的文献库、页面和文献，可关闭）；自动检查更新和自动下载更新（macOS、Windows：后台下载新版本并核对校验值，下载好了问一次是否重启更新，重启后回到原来的界面；关闭后只提示有新版本）。
- **外观**：跟随系统 / 浅色 / 深色，文献列表的行高。
- **快捷键**：命令面板、搜索、添加文献、导入 PDF、打开助手、收起侧边栏、阅读模式、PDF 缩放等都可以改键、移除或恢复默认。
- **AI**：可以放进多个模型服务，助手、批量筛选、翻译、整理全文各用哪一个分别指定（没指定的跟随助手的模型）；每项任务下写着它管哪些功能：助手的模型也用于单篇提问、向导拟检索式、图片库的图注和标签、写作页的改写、润色和配引用，批量筛选的模型也用于提取，翻译的模型也用于 PDF 选段和写作页的候选句检索词。三种接口：Claude API、OpenAI 兼容的 chat/completions、OpenAI 的 Responses（/responses）。每个模型有自己的思考设置：默认（不发送参数）、关闭，或低到最高五档；翻译这样的任务可以用一个关闭思考的小模型。模型服务可以单独指定代理，或者填 direct 不走代理。
- **网络**：全局代理（http、https、socks4、socks5 等），文献检索、元数据查询、检查更新和模型请求都经过它；留空时跟随环境变量 ALL_PROXY / HTTPS_PROXY / HTTP_PROXY。命令行 `wisp` 用同一个设置。
- **关于**：版本、检查更新（有新版本时在这里下载更新、重启并更新）、项目主页。
