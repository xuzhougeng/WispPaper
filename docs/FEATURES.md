# 功能详解

## 多个独立的文献库

启动后的首页是文献库列表。每个文献库有自己的名称、主题描述和标识色，是数据目录下的一个独立文件夹（数据库、PDF、自定义词条都在里面），可以单独备份或拷走。

## 收集

- 粘贴 DOI 或 PMID：从 Crossref 和 Europe PMC 查询题目、作者、期刊、年份、摘要。
- 拖入或选择 PDF：提取文字，在前两页找 DOI 并查询元数据；找不到 DOI 时以文件名建条目。
- 没有 DOI 的文献可以「按题目补全」（文献详情里的按钮）：题目取自文献本身，题目还是文件名时取自 PDF 首页（可以改），再到 Crossref、Europe PMC 和 arXiv 查找相近的记录。每个来源单独说明查到几条、没有查到还是没查成。候选列出题目、作者、年份、期刊和编号，标出与所查一致和不一致的地方；预印本和正式发表的版本是两条记录。点一条候选逐个字段核对：默认只勾选现在空着的字段和只是文件名的题目，已有的内容勾选后才替换；题目和所查不一样的记录不预先勾选任何字段。候选已是库里另一篇文献时不能写入。发出去的只有题目、作者和年份，不上传 PDF，不经过模型，也不打开浏览器抓取网页；一篇文献可以一直没有 DOI。
- 一次导入多个 PDF 时，侧栏下方有一块进度（已完成几个、正在读哪个文件），换到别的页面也看得到。读完后它变成一份汇总，直到你关掉：新增几篇、附到已有文献几篇、在回收站里所以没导入的几篇，以及还要处理的（没认出 DOI、待补全题目和作者的；没读出文字的）。「查看明细」逐个文件列出结果和原因，点一行打开那篇文献。
- 导入 BibTeX / RIS；手动录入。
- 从 Zotero 6 / 7 本地数据库导入个人库与群组库的文献信息、标签、笔记和本地 PDF；分类路径转为标签。只读源库、复制附件，已有记录保留并补 PDF；进度和结果明细列出重复、回收站及失败原因。见 [Zotero 导入教程](ZOTERO.md)。
- 按 DOI、PMID、题目去重，重复导入不会产生重复条目。

## 整理

- 搜索（题目、作者、DOI、标签、词条、摘要、笔记）、筛选、排序。
- 阅读状态、收录判断、收藏、标签、笔记。
- **自定义词条**：每个文献库自己定义字段（文本 / 多值 / 单选），可填写、筛选、作为表格列。
- 「全文」一栏有四种状态：无全文、有链接、已存 PDF，以及「PDF 无文字」（存了 PDF 但没读出文字，全文暂时不能用于提问）。可以按它筛选。
- 回收站：删除的文献可恢复，并继续阻止同一篇被重复导入。
- 导出 BibTeX、CSV（当前列表）。
- 侧边栏：拖动它右侧的分隔线改变宽度，宽度会记住；双击分隔线、点左上角的按钮或按 `Ctrl` / `⌘` + `B` 收起，把窗口让给列表和文献，再点按钮或按快捷键回来。拖到很窄也会收起。

## PDF 预览

在详情面板里直接看 PDF。渲染用纯 Rust 的 [hayro](https://github.com/LaurenzV/hayro)，不依赖系统 PDF 库。

- 面板宽度：拖动文献列表和详情之间的分隔线，宽度会记住；双击分隔线恢复默认。右上角的展开按钮仍然一键让出阅读宽度。
- 阅读模式：PDF 工具栏上的「阅读模式」（`Ctrl` / `⌘` + `Shift` + `F`，可改键）收起侧边栏和文献列表，整个窗口留给这篇文献，顶上只剩题目、三个标签页和「退出阅读」；`Esc` 退出。进出阅读模式，PDF 停在原来读到的地方，对话和没发出的问题也都还在。
- 缩放：工具栏上有缩小、当前比例、放大；点比例可选「适应宽度」「适应整页」或 50% 到 400%。`Ctrl` / `⌘` 加 `+`、`-`、`0` 是放大、缩小、适应宽度（可在「设置 › 快捷键」里改），`Ctrl` / `⌘` 加滚轮以指针位置为中心缩放。页面比面板宽时，横向滚动或按住 Shift 滚动来左右移动。
- 选字：在页面上拖动选中文字（限于一页之内），`Ctrl` / `⌘` + `C` 复制，或用选区下方的「复制」「添加到对话」。没有文字层的 PDF 选不了字。
- 标注：选中文字后点「下划线」或「高亮」。右上角「标注」列出当前 PDF 的所有标注，可以定位原文、编辑笔记或删除。标注单独存入文献库数据库，在阅读器中按页面坐标叠加显示，缩放和重新打开后仍保留；原始 PDF 文件不变，用外部阅读器打开原文件时不会显示这些标注。标注绑定具体附件，移除附件时同时移除；文献进入回收站时保留，恢复后可继续查看。内置助手、CLI 和 MCP 可通过 `list_pdf_annotations` 读取原文、笔记、类型、页码和位置；用户笔记与论文原文分开提供。
- 截图：工具栏的「截图」之后，在页面上框出一块（一张图、一个表格）。框好后可以「收藏到图片库」，或者「用这张截图提问」：它会作为图片加到提问的输入框上方。
- 页面先出一张粗图，随即换成按显示大小渲染的清晰图；单页图像有上限（约 2400 万像素），在高分屏上放大到 300% 以上会略微变软。

## 图片库

从文献的 PDF 里截下来的图和表，收在左侧「收藏」里：「收藏」上面有「文献 / 图片」两个切换，星标的文献和收藏的图片各占一边。

- 收藏：在 PDF 工具栏点「截图」，在页面上框出一张图或一个表，点「收藏到图片库」。弹出的对话框里是这张截图和四个字段：图号、图注、标签、备注。图号和图注会从这一页的文字里读出来（认 `Fig. 2 | …`、`Figure 3.`、`Table 1`、`Extended Data Fig. 4`、`图 3` 这些写法；图的图注在它下面找，表的在它上面找），收藏前看一眼、改掉不对的地方。收藏后仍然留在截图状态，可以接着框下一张。
- 让模型来写：图注、标签、备注三个字段名的右边各有一个 AI 图标。点一下，提问用的模型会看着这张图写出这一项：图注（连同图号）、3 到 5 个标签（优先用图片库里已有的）、两到四句解读。写出来的内容在字段里，可以改，也可以撤销；和别的字段一样，点「收藏」或「保存」才会存下来。图片会发给模型服务。
- 标签：图片有自己的标签，和文献的标签分开，适合按图的类型和用途来分（配色、UMAP、示意图……）。对话框里列出已有的标签，点一下就加上。
- 浏览：卡片上是缩略图、图号、图注、出处和标签。可以搜索图注、图号、标签、备注，以及所属文献的题目、作者、期刊和年份；点一个标签只看带它的图片。
- 回到原文：点开一张图片，「打开原文」会在右侧打开它所在的 PDF，并滚到截图的位置；「用这张图提问」把它带进这篇文献的对话；还可以复制图片、另存为文件。卡片上点右键也有这些操作。
- 文献进了回收站，它的图片暂时不显示，恢复后回来；文献彻底删除时图片跟着移出。移出的图片文件不会被删除，而是移到文献库文件夹下的 `removed` 文件夹。
- 图片文件在文献库文件夹的 `figures` 里，和数据库、PDF 一起备份、拷走。命令行和 MCP 的 `list_figures` 可以查询它们。

## 全文的文字

提问、检索全文和写作页用的是从 PDF 里读出的文字。

- 读取：先按字形的位置读（保留页面上的分段），不行再换另一种读取方式。两种都读不出时，文件照样保存，但状态是「PDF 无文字」。
- 原因分开说：文件打不开、设了打开密码、两种方式都解析不了（不代表它是扫描件）、字体没有给出文字编码、页面上没有文字层。助手得到的也是同一句原因，并被要求照此转述，不去猜文件是不是扫描件或加了密。
- 在文献详情的「文件」里可以看到每个文件读出了几页文字；没读出的，下面写着原因和两个按钮：「重新读取」，以及「让模型读页面」（把页面作为图片交给能看图的模型，读出的文字按页保存，并记下是哪个模型读的；需要在「设置 › AI」里配置模型）。
- 在「助手」里向文献库提问时，顶部的范围说明会写出其中有几篇的 PDF 没读出文字。
- 文件一行会写出有文字的页数（「15 页中 14 页有文字」）；由查找得来的文件还会写出来源和版本。

## 查找开放全文

检索导入的文献大多只有记录，没有 PDF。「缺 PDF」视图顶部的按钮可以替这些文献找开放获取的全文，下载后附到原来的条目上，并读出文字；单篇文献在「PDF」标签里也有「查找开放全文」。

- 只找可以免费合法获取的版本：arXiv；OpenAlex 和 Europe PMC 列出的开放获取文件；以及被这两个索引标为开放获取的 Springer / BMC、Nature、Frontiers 文章在出版商那里的 PDF。不登录，不绕过付费墙，找不到就说没有。
- 查找时会把文献的 DOI 或 PMID 发给 OpenAlex、Europe PMC 和出版商；没有 DOI、PMID 或 arXiv 编号的文献查不了。
- 侧栏下方显示可点击的分段进度条：绿色为已保存，黄色为未找到地址，红色为下载失败，蓝色为正在查找，灰色为等待处理。点击打开实时详情，查看正在处理的论文、逐篇结果和失败原因；收起弹窗后继续查找，完成后仍可重新打开。
- 详情中可以停止查找：不再开始下一篇，已经发出的请求完成后仍会记入结果。保留本次总数，并显示未处理的数量。「未找到地址」仅表示本次未检索到候选 PDF 地址，不代表论文一定没有开放全文。取回来的不是 PDF（登录页、验证页）不会被存成 PDF。
- PDF／文件夹导入和 Zotero 导入使用相同的侧栏进度条与实时详情弹窗。绿色为已导入，黄色为需要完善信息或附件，红色为导入失败，蓝色为处理中，灰色区分已跳过与等待中。PDF 导入详情会列出正在读取的文件；收起后继续导入。
- 没有取到的，打开文献的链接自己下载，再把 PDF 拖进窗口，它会按 DOI 附到原条目上。
- 同一件事也是一个工具 `find_pdf`：`wisp find_pdf`、MCP 和窗口里的助手都能用；助手用之前会先问你。

## 建库向导

- 新建文献库后先问从哪里开始：从检索文献开始、导入已有的文献，或者先空着。
- 从检索开始：写下主题或关键词，助手为所选的数据库各拟几条取向不同的检索式，并逐条试检索；你按命中的文献选出靠谱的，保存并导入。已有的文献库也可以从「检索与导入」页进入。

## 检索与导入

- 为 PubMed、Europe PMC、Crossref、arXiv 保存检索式；「试检索」显示数据库命中总数和最新的记录，并标出哪些已在库中。
- 「运行并导入」把新文献加入文献库（都是「待判断」），已有的跳过；每次导入可以整批撤销，处理过的文献会保留。
- 自动更新（默认关闭）：每 6 小时、每天或每周运行已启用的检索式。应用开着时每分钟检查一次；关着时错过的，下次打开时补上；失败的最多一小时后重试。不开窗口时可以让系统的计划任务定期执行 `wisp sync_searches`（见[命令行与 MCP](CLI.md)）。

## 筛选

- 「筛选」页列出待判断的文献。助手阅读每一篇（有全文读全文，否则读摘要），给出建议、理由、一句逐字引自原文的依据和把握；引文不在原文里的不会被当作依据。
- 批量进行：几篇同时读（1 到 8 篇，在「设置 › AI」里定），页面上有进度条和正在读的文献。个别文献没判断成不会打断这一轮，连续三篇失败才停下；没判断成的留到下一轮。
- 判断完的队列按助手的建议分组（已纳入、相关、证据不足、不相关、还没有建议），可以只看其中一组。
- 建议只是建议：每一篇的收录判断由你确认，可以采纳，也可以另选；看过一组之后，也可以把整组按建议一次采纳（会先问一遍）。外部 agent 通过 MCP 或命令行只能提建议。

## 提取

- 让助手替你填自定义词条：它逐篇阅读（有全文读全文，否则读摘要），为每个词条提出取值，并摘一句逐字引自原文的依据；引文不在原文里的不会被当作依据。文中没有说明的，它就答没有，不猜。
- 从三处开始：在文献列表里选中几篇，右键「让助手填写词条…」；在「自定义词条」里点「让助手填写…」，范围是当前列表；或在一篇文献详情的词条旁点 ✦，只问那一项。开始前选要问哪些词条，对话框会说要读几篇、几篇有全文。已经填好或已经问过的不会重复问，除非勾选「重新提取」。
- 词条可以带一句说明（「自定义词条」里填），告诉助手要找什么，例如“研究用的物种，写学名”。「要点」是现成的一个：一两句话概括这篇文献发现了什么，没有时对话框里可以一键添加，它就是一个普通的文本词条，也可以作为表格的一列。
- 几篇同时读（篇数和模型与筛选相同，在「设置 › AI」里定），侧栏和「提取」页上有进度，可以随时停止。个别文献没读成不会打断这一轮，连续三篇失败才停下；没有摘要也没有全文的文献不会去问。
- 「提取」页列出等你确认的取值，一行是一篇文献的一个词条：取值、原文里的那句话（有页码时点击打开 PDF 并高亮这句）、出自哪篇文献。可以只看某一个词条。默认勾选的是词条还空着、且找到了原文依据的取值；词条已有别的值的、没有原文依据的不勾选，留给你判断。
- 单选词条的取值只能是它的选项之一：助手的回答对不上任何选项时不会写入，那一行列出选项让你选，或者留着不写。多值词条写入时保留已有的值，新的加在后面。
- 「写入」把勾选的取值一次写进词条（要么全部写入，要么都不写），写入之后可以撤销；用不上的可以「清除」，清除的不再列出，也不会再问。写入之前什么都不会改动。
- 写入之后，这句原文留在文献详情里那个词条的下面：以后看到一个取值，可以点回它的出处。
- 外部 agent 通过 MCP 或命令行的 `suggest_field` 只能提出取值，同样出现在这里等你确认。

## 写作：导入已有的稿件，带批注审阅

- 稿件可以从零开始写，也可以从已有的文件开始：写作页「稿件」菜单里的「导入 Word / Markdown 文件…」，或者把 .docx 拖进窗口（在写作页上，.md 和 .txt 也可以）。标题变成各节；没有用标题样式的 Word 文件，按「摘要」「引言」「方法」这类常见的节名分节。
- 助手在对话里写的东西也能接着改：综述记录写好的各节，在「稿件」菜单里是「从助手的综述新建」（对话里也有「存为新稿件」）；一条回答可以「保存为新稿件」或「插入到稿件」。
- Word 文件里合作者留的批注一并读入，显示在右侧的「批注」页（和「候选句」并排的另一页）；被批注的文字在稿件里有底色，点批注上的引文回到那处文字。来自 Word 的批注只能标为已处理，不会从文件里删掉。
- 「让助手审阅这一节」（选中文字时只审阅选中的部分，可以先写一句想让它看什么）：助手像在 Word 的审阅模式里那样留批注，每条指向一处原文；需要改文字的带着「建议改为」，并优先回应合作者的批注。只有你点「采纳修改」才会改稿件：批注随之落在改后的文字上，保留原文，可以「撤回修改」。也可以「采纳全部」。再审一次会替换上一轮还没处理的批注。
- 选中文字后，段落操作在选区旁的浮动菜单里出现，分成三组：「找句子」「配引用」只在文献库里查找，不改文字；「润色」「译成…」「仿写」和你自己的命令给出改后的文字，由你决定是否替换；最后是「批注」。每个按钮悬停时说明它会给出什么。菜单随滚动定位，按 Esc 或点击外部收起。没有选中文字时，稿件下方仍保留当前段落的操作。
- 「仿写」参照文献库里与这段最相近的句子改写：右边的候选句不是为这段找的时候，它先找一遍再改写；借鉴的是结构和措辞，意思以你写的为准，用到某篇文献的发现时补上 `[@Key]`。
- 在来自 Word 的稿件里，用「润色」「仿写」「译成…」替换一段、或用「配引用」加了引用之后，那一段上自动留一条助手的批注（做了什么、原文是什么）。
- 导出为 Word：来自 Word 的稿件写回原文件，没改的段落原样保留（版式、表格、图片、脚注、域代码都在原处），改过的段落只在原有的格式片段里改字；批注写成 Word 自己的批注。可以选「改动记为修订」，对方在 Word 里逐条接受或拒绝。从零写的稿件导出时同样带上批注。署名在「设置 › 通用 › 写作」。
- 表格和图片不进稿件的文字，留在 Word 文件里；Word 里未接受的修订按接受后的文字读入。

## 翻译

- 文献详情的「摘要」旁有「显示译文」：题目和摘要在原位置换成译文。打开以后，之后点开的每一篇都会翻译，直到点「显示原文」。
- 译过的文字保存在文献库里，同一段文字不会请求第二次。翻译的要求（目标语言、术语、格式）可以在「设置 › AI」里改；改了以后按新的要求重新翻译。

## 助手与提问

- 左侧的「助手」是和整个文献库的对话：可以提问，也可以交代一件事（试检索外部数据库、运行检索式导入、查找开放全文、提出筛选建议、分阶段写综述）。开始对话前，页面按「找文献、读文献、整理、写」列出它能做的事：点一句话就发出去，点一个命令则把它放进输入框，等你写上后面的内容。
- 助手可以替你整理文献：加或去标签、设星标、改阅读状态、往「我的笔记」末尾追加一段（注明是助手所记，不覆盖已有内容）。它动手之前，对话里会列出每一篇要改什么，等你同意；同意后一次写入，其中一篇有问题就一篇都不写。收录判断和自定义词条不在其中：前者它只能在筛选页提建议，后者在提取页提建议。
- 助手可以读你在写作页的稿件（只读），所以能就稿件提意见，或按稿件已有的内容接着写。回答下面的「插入到稿件」把这条回答加到你选的那一节末尾，选中一段时是「所选插入稿件」；`[P3 p.5 "…"]` 这样的引用变成稿件用的 `[@Key, p. 5]`，那一节原来的内容先留一份历史版本。
- 写作页的段落操作里有「配引用」：为选中的文字（或光标所在的段落）逐句找文献库里可以引用的文献。它不改写文字，结果是一张清单：每句话下面列出找到的文献、模型认为它贴切的理由，以及这篇文献自己的一句原文（全文里的带页码，点右上角的图标在 PDF 里看这句）。模型核对后认为可以引用的已经勾好，其余相近的收在「还有 N 篇相近的」里，可以自己改选；点「插入 N 条引用」才把 `[@Key]` 加到各句句末，可以撤销。稿件用中文写、文献是英文的也能找：翻译用的模型先把每句话变成文献那种语言的检索词。没有配置模型时，列出按用词找到的相近文献，不勾选，由你判断。
- 引用带着出处：右边「参考文献」页里，每篇文献下面是引用它的那句话所依据的文献原文，附所在的部分和页码，点一下就在 PDF 里翻到那一页并高亮这句。光标停在稿件的一处引用上，稿件下方会出现一行：这是哪篇文献、这句话依据的是它的哪句原文；参考文献页同时滚到那篇文献并标出这条出处。出处在引用时记下：在候选句上点「引用」、在「配引用」里勾选插入、把助手的回答（它引的原句）插入稿件。已经写好的引用可以事后找：点参考文献列表上方带数字的星标（或光标所在引用那一行的星标），助手到每篇被引的文献里检索，再由模型核对哪一句是依据；核对后认为文献里没有依据的，会在那篇文献下面用提醒色标出，方便检查引错的地方。出处只记在文献库里，稿件的文字仍是 `[@Key]`；句子改写后仍按内容对得上，不要的出处可以点 × 去掉。
- 向文献库提问：范围是当前列表（受视图、搜索、筛选影响），模型读到每篇的记录、笔记，以及已存 PDF 中与问题相关的页面。顶部的「文献」展开这些文献的列表：提问前是当前列表，提问后带上这次对话里的编号（P1、P2…）、每篇交给模型的是完整记录还是只有题目、给了几页全文、全文是否可读。点一行在右侧打开那篇文献，对话不动，范围也不变。
- 就单篇文献提问：模型读到该文献的记录和全文。点「提问」后窗口换成提问的布局：侧栏收起，文献成为左边一条窄列表（带搜索，↑↓ 换一篇），中间是对话，右边是这篇的 PDF，边读边问。没有 PDF 的文献布局不变，右边是「添加 PDF」和「查找开放全文」。按 Esc、点「退出提问」或切回「信息」就回到完整列表；点 PDF 工具栏右端的 × 收起 PDF，之后提问只在右侧面板里进行，点「对照 PDF」再展开。窄列表与对话、对话与 PDF 之间的分隔线都可以拖动，宽度会记住，双击恢复默认。
- 在 PDF 上选中的原文可以「添加到对话」：它带着页码出现在输入框上方，提问时作为引文交给模型，回答引用它时可以原路跳回那一页。文献库的对话和这篇文献的对话同时可见时，可以选加到哪一个。也可以把页面上框出的一块作为图片提问。
- 材料不够时，助手会自己调用工具在整个文献库里检索全文、按页翻阅、查询记录。一轮调用收成一行（「检索全文 ×2 · 读取全文」），点开看每次调用和结果；只读的调用并行执行。
- 助手要运行检索式导入文献、撤销导入或删除检索式时，会先停下来等你同意：允许这一次、这次对话里都允许，或者不允许。
- 回答过程中可以随时停止；已经写出的部分留在对话里，可以接着问。模型服务繁忙或连接失败时自动重试两次。
- 提问可以带图片（最多 8 张）：直接粘贴截图，或点输入框左边的「+」选择文件。过大的图片会先缩小，TIFF、BMP 会转成 PNG。所选的模型需要支持图片输入。
- 回答按 Markdown 排版：标题、加粗和斜体、列表、表格、引用、代码块，链接可以点开。
- 助手引的原句会和文献库里保存的那一页文字逐字比对（只比字母和数字，换行和连字符不算），结果写在出处卡片上：原文一致、原文在另一页（点击会去实际的那一页）、只对上开头的百分之几、原文里没有这句、没有全文可核对。这只说明这句话在不在原文里；它是否足以支持论断，由你判断。`/verify` 让助手把上一个回答逐条列成「论断、原文摘录、支持到什么程度」，摘录照样经过这道比对。
- 回答里的文字可以拖动选中（跨段也可以），`Ctrl` / `⌘` + `C` 复制，或用回答下面的「复制所选」「引用到输入框」；后者把选中的话作为引用块放进输入框，接着写你的问题。
- 回答正文里的 `[P3 p.5 "…"]` 和回答下面的出处卡片都可以点击：打开这篇文献的 PDF 并跳到所引的页；助手引了原句时，这句话会在页面上高亮（那一页没有就在全文里找，找不到会明说）。筛选建议里的原文依据同样可以点击。
- 一个回答引了很多文献时，下面先列出前 8 个出处，其余的点「另外 N 个出处」展开。
- 输入 `/` 弹出命令列表，继续输入（英文名或中文说明里的字）筛选，↑↓ 选择，Enter 或 Tab 确认：`/search 词语` 在全文和记录里检索；`/cite 一段文字` 为这段文字逐句从库里找可以引用的文献；`/review 主题` 分阶段撰写综述；`/compare P1 P3` 比较几篇文献的方法和结论；`/write 部分 要写的意思` 从文献库里找这一部分的候选句来写一段；`/verify` 逐条核对上一个回答（或后面写的内容）的依据；`/new` 开始新对话。
- 常用的提问可以存成自己的命令（设置 › AI › 命令）：起一个名称，写一句说明和一段模板，例如 `/style-check` 检查空泛、重复的表达。模板里的 `{}` 换成命令后面写的内容；不写 `{}` 的模板可以单独使用。自己的命令和内置命令一起出现在列表里，标着「自定义」，选中后不会自动发送。它只是一段提示：不运行脚本，不增加工具，也不绕过确认。对话里保存着当时实际发出的内容，以后修改或删除命令，不会改变旧对话问过什么。
- 支持 Claude API、OpenAI 兼容的 chat/completions 和 OpenAI 的 Responses 接口。
- 单篇提问里，每条回答下面有「存为笔记」：先给你看一遍、可以改，确认后加到这篇文献「我的笔记」的末尾，不覆盖已有内容。对话里的 `[P1 p.5 "…"]` 会去掉只在这次对话里有意义的编号，页码和摘录保留；末尾注明这是模型的回答、没有核对原文。笔记本来就随文献记录一起提供给以后的提问。
- 对话保存在文献库里。没有配置模型时也能看历史对话，只是不能接着问；点「新对话」后会提示上一段已保存。点「历史」列出向文献库（或向这篇文献）提过的问题，点开一次对话可以接着问：模型会按文献库现在的内容重新读材料，以前回答里的 `[P3]` 仍然指向原来那篇文献。历史对话可以逐条删除。
- `/review` 让这次对话带上一份综述记录：写作要求、初步框架和大纲由你分别确认，大纲确认后一节一节保存正文，最后记下检查。初步框架来自已有综述（它们各问什么、怎么组织、哪里没讲到），大纲再对照它、按文献库里的研究重建；没有可参照的综述可以跳过这一步。对话上方写着走到哪一步，回答下面只有这一步用得上的按钮；也可以只记回答里选中的一段。「查看记录」里每一项都能直接编辑。记录保存在文献库，从历史对话可以接着写；已保存的正文按顺序存为新稿件，对话里的引用转成写作页的引用。完整操作见[分阶段撰写综述](TUTORIAL.md#9-分阶段撰写综述)。
- 保存一节正文时，它的每处引用成为一条证据：论断是引用所在的句子，来源是文献和页码，摘录的原句已和文献的文字比对。来源是否支持论断由你判断（支持、部分支持、不支持、无法判断）；句子或来源的内容变了，判断收回或标为待重新判断。没有引用的句子也可以手动记下依据。

## 设置

单独的设置页（首页或文献库侧栏的「设置」，默认 `Ctrl` / `⌘` + `,`），改动即时保存。

- **通用**：数据目录、自动检查更新。
- **外观**：跟随系统 / 浅色 / 深色，文献列表的行高。
- **快捷键**：搜索、添加文献、导入 PDF、打开助手、收起侧边栏、阅读模式、PDF 缩放等都可以改键、移除或恢复默认。
- **AI**：可以放进多个模型服务，助手、批量筛选、翻译、整理全文各用哪一个分别指定（没指定的跟随助手的模型）；每项任务下写着它管哪些功能：助手的模型也用于单篇提问、向导拟检索式、图片库的图注和标签、写作页的改写、润色和配引用，批量筛选的模型也用于提取，翻译的模型也用于 PDF 选段和写作页的候选句检索词。三种接口：Claude API、OpenAI 兼容的 chat/completions、OpenAI 的 Responses（/responses）。每个模型有自己的思考设置：默认（不发送参数）、关闭，或低到最高五档；翻译这样的任务可以用一个关闭思考的小模型。模型服务可以单独指定代理，或者填 direct 不走代理。
- **网络**：全局代理（http、https、socks4、socks5 等），文献检索、元数据查询、检查更新和模型请求都经过它；留空时跟随环境变量 ALL_PROXY / HTTPS_PROXY / HTTP_PROXY。命令行 `wisp` 用同一个设置。
- **关于**：版本、检查更新、项目主页。
