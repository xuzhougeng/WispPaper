# 功能详解

## 多个独立的文献库

启动后的首页是文献库列表。每个文献库有自己的名称、主题描述和标识色，是数据目录下的一个独立文件夹（数据库、PDF、自定义词条都在里面），可以单独备份或拷走。

## 收集

- 粘贴 DOI 或 PMID：从 Crossref 和 Europe PMC 查询题目、作者、期刊、年份、摘要。
- 拖入或选择 PDF：提取文字，在前两页找 DOI 并查询元数据；找不到 DOI 时以文件名建条目。
- 没有 DOI 的文献可以「按题目补全」（文献详情里的按钮）：题目取自文献本身，题目还是文件名时取自 PDF 首页（可以改），再到 Crossref、Europe PMC 和 arXiv 查找相近的记录。每个来源单独说明查到几条、没有查到还是没查成。候选列出题目、作者、年份、期刊和编号，标出与所查一致和不一致的地方；预印本和正式发表的版本是两条记录。点一条候选逐个字段核对：默认只勾选现在空着的字段和只是文件名的题目，已有的内容勾选后才替换；题目和所查不一样的记录不预先勾选任何字段。候选已是库里另一篇文献时不能写入。发出去的只有题目、作者和年份，不上传 PDF，不经过模型，也不打开浏览器抓取网页；一篇文献可以一直没有 DOI。
- 一次导入多个 PDF 时，侧栏下方有一块进度（已完成几个、正在读哪个文件），换到别的页面也看得到。读完后它变成一份汇总，直到你关掉：新增几篇、附到已有文献几篇、在回收站里所以没导入的几篇，以及还要处理的（没认出 DOI、待补全题目和作者的；没读出文字的）。「查看明细」逐个文件列出结果和原因，点一行打开那篇文献。
- 导入 BibTeX / RIS；手动录入。
- 从 Zotero 6 / 7 本地数据库导入个人库与群组库的文献信息、标签、笔记和本地 PDF；分类路径转为标签。只读源库、复制附件，已有记录保留并补 PDF；进度和结果明细列出重复、回收站及失败原因。见 [Zotero 导入教程](ZOTERO.md)。
- 按 DOI、PMID、题目去重，重复导入不会产生重复条目。

## 整理

- 搜索（题目、作者、DOI、标签、词条、摘要、笔记）、筛选、排序。
- 阅读状态、收录判断、收藏、标签、笔记。
- **自定义词条**：每个文献库自己定义字段（文本 / 多值 / 单选），可填写、筛选、作为表格列。
- 「全文」一栏有四种状态：无全文、有链接、已存 PDF，以及「PDF 无文字」（存了 PDF 但没读出文字，全文暂时不能用于提问）。可以按它筛选。
- 回收站：删除的文献可恢复，并继续阻止同一篇被重复导入。
- 导出 BibTeX、CSV（当前列表）。
- 侧边栏：拖动它右侧的分隔线改变宽度，宽度会记住；双击分隔线、点左上角的按钮或按 `Ctrl` / `⌘` + `B` 收起，把窗口让给列表和文献，再点按钮或按快捷键回来。拖到很窄也会收起。

## PDF 预览

在详情面板里直接看 PDF。渲染用纯 Rust 的 [hayro](https://github.com/LaurenzV/hayro)，不依赖系统 PDF 库。

- 面板宽度：拖动文献列表和详情之间的分隔线，宽度会记住；双击分隔线恢复默认。右上角的展开按钮仍然一键让出阅读宽度。
- 缩放：工具栏上有缩小、当前比例、放大；点比例可选「适应宽度」「适应整页」或 50% 到 400%。`Ctrl` / `⌘` 加 `+`、`-`、`0` 是放大、缩小、适应宽度（可在「设置 › 快捷键」里改），`Ctrl` / `⌘` 加滚轮以指针位置为中心缩放。页面比面板宽时，横向滚动或按住 Shift 滚动来左右移动。
- 选字：在页面上拖动选中文字（限于一页之内），`Ctrl` / `⌘` + `C` 复制，或用选区下方的「复制」「添加到对话」。没有文字层的 PDF 选不了字。
- 截图提问：工具栏的「截图提问」之后，在页面上框出一块（一张图、一个表格），它会作为图片加到提问的输入框上方。
- 页面先出一张粗图，随即换成按显示大小渲染的清晰图；单页图像有上限（约 2400 万像素），在高分屏上放大到 300% 以上会略微变软。

## 全文的文字

提问、检索全文和写作页用的是从 PDF 里读出的文字。

- 读取：先按字形的位置读（保留页面上的分段），不行再换另一种读取方式。两种都读不出时，文件照样保存，但状态是「PDF 无文字」。
- 原因分开说：文件打不开、设了打开密码、两种方式都解析不了（不代表它是扫描件）、字体没有给出文字编码、页面上没有文字层。助手得到的也是同一句原因，并被要求照此转述，不去猜文件是不是扫描件或加了密。
- 在文献详情的「文件」里可以看到每个文件读出了几页文字；没读出的，下面写着原因和两个按钮：「重新读取」，以及「让模型读页面」（把页面作为图片交给能看图的模型，读出的文字按页保存，并记下是哪个模型读的；需要在「设置 › AI」里配置模型）。
- 向文献库提问时，顶部的范围说明会写出其中有几篇的 PDF 没读出文字。
- 文件一行会写出有文字的页数（「15 页中 14 页有文字」）；由查找得来的文件还会写出来源和版本。

## 查找开放全文

检索导入的文献大多只有记录，没有 PDF。「缺 PDF」视图顶部的按钮可以替这些文献找开放获取的全文，下载后附到原来的条目上，并读出文字；单篇文献在「PDF」标签里也有「查找开放全文」。

- 只找可以免费合法获取的版本：arXiv；OpenAlex 和 Europe PMC 列出的开放获取文件；以及被这两个索引标为开放获取的 Springer / BMC、Nature、Frontiers 文章在出版商那里的 PDF。不登录，不绕过付费墙，找不到就说没有。
- 查找时会把文献的 DOI 或 PMID 发给 OpenAlex、Europe PMC 和出版商；没有 DOI、PMID 或 arXiv 编号的文献查不了。
- 侧栏下方有进度（可以停止），结束后是汇总和明细：已保存、没有开放全文、找到了地址但没有取到文件（有的出版商只把文件交给浏览器）。取回来的不是 PDF（登录页、验证页）不会被存成 PDF。能自动取回的比例取决于出版商，arXiv、Springer / BMC、Nature、Frontiers 的开放获取文章通常可以，MDPI、Elsevier、Wiley 等多半不行。
- 没有取到的，打开文献的链接自己下载，再把 PDF 拖进窗口，它会按 DOI 附到原条目上。
- 同一件事也是一个工具 `find_pdf`：`wisp find_pdf`、MCP 和窗口里的助手都能用；助手用之前会先问你。

## 建库向导

- 新建文献库后先问从哪里开始：从检索文献开始、导入已有的文献，或者先空着。
- 从检索开始：写下主题或关键词，助手为所选的数据库各拟几条取向不同的检索式，并逐条试检索；你按命中的文献选出靠谱的，保存并导入。已有的文献库也可以从「检索与导入」页进入。

## 检索与导入

- 为 PubMed、Europe PMC、Crossref、arXiv 保存检索式；「试检索」显示数据库命中总数和最新的记录，并标出哪些已在库中。
- 「运行并导入」把新文献加入文献库（都是「待判断」），已有的跳过；每次导入可以整批撤销，处理过的文献会保留。
- 自动更新（默认关闭）：每 6 小时、每天或每周运行已启用的检索式。应用开着时每分钟检查一次；关着时错过的，下次打开时补上；失败的最多一小时后重试。不开窗口时可以让系统的计划任务定期执行 `wisp sync_searches`（见[命令行与 MCP](CLI.md)）。

## 筛选

- 「筛选」页列出待判断的文献。助手阅读每一篇（有全文读全文，否则读摘要），给出建议、理由、一句逐字引自原文的依据和把握；引文不在原文里的不会被当作依据。
- 批量进行：几篇同时读（1 到 8 篇，在「设置 › AI」里定），页面上有进度条和正在读的文献。个别文献没判断成不会打断这一轮，连续三篇失败才停下；没判断成的留到下一轮。
- 判断完的队列按助手的建议分组（已纳入、相关、证据不足、不相关、还没有建议），可以只看其中一组。
- 建议只是建议：每一篇的收录判断由你确认，可以采纳，也可以另选；看过一组之后，也可以把整组按建议一次采纳（会先问一遍）。外部 agent 通过 MCP 或命令行只能提建议。

## 翻译

- 文献详情的「摘要」旁有「翻译」：题目和摘要译成中文，显示在原文上方。打开以后，之后点开的每一篇都会翻译，直到点「隐藏译文」。
- 译过的文字保存在文献库里，同一段文字不会请求第二次。翻译的要求（目标语言、术语、格式）可以在「设置 › AI」里改；改了以后按新的要求重新翻译。

## 提问

- 向文献库提问：范围是当前列表（受视图、搜索、筛选影响），模型读到每篇的记录、笔记，以及已存 PDF 中与问题相关的页面。顶部的「文献」展开这些文献的列表：提问前是当前列表，提问后带上这次对话里的编号（P1、P2…）、每篇交给模型的是完整记录还是只有题目、给了几页全文、全文是否可读。点一行在右侧打开那篇文献，对话不动，范围也不变。
- 就单篇文献提问：模型读到该文献的记录和全文。面板够宽时，对话在左、这篇的 PDF 在右，边读边问；面板窄时点「对照 PDF」展开。
- 在 PDF 上选中的原文可以「添加到对话」：它带着页码出现在输入框上方，提问时作为引文交给模型，回答引用它时可以原路跳回那一页。文献库的对话和这篇文献的对话同时可见时，可以选加到哪一个。也可以把页面上框出的一块作为图片提问。
- 材料不够时，助手会自己调用工具在整个文献库里检索全文、按页翻阅、查询记录。一轮调用收成一行（「检索全文 ×2 · 读取全文」），点开看每次调用和结果；只读的调用并行执行。
- 助手要运行检索式导入文献、撤销导入或删除检索式时，会先停下来等你同意：允许这一次、这次对话里都允许，或者不允许。
- 回答过程中可以随时停止；已经写出的部分留在对话里，可以接着问。模型服务繁忙或连接失败时自动重试两次。
- 提问可以带图片（最多 8 张）：直接粘贴截图，或点输入框左边的「+」选择文件。过大的图片会先缩小，TIFF、BMP 会转成 PNG。所选的模型需要支持图片输入。
- 回答按 Markdown 排版：标题、加粗和斜体、列表、表格、引用、代码块，链接可以点开。
- 助手引的原句会和文献库里保存的那一页文字逐字比对（只比字母和数字，换行和连字符不算），结果写在出处卡片上：原文一致、原文在另一页（点击会去实际的那一页）、只对上开头的百分之几、原文里没有这句、没有全文可核对。这只说明这句话在不在原文里；它是否足以支持论断，由你判断。`/verify` 让助手把上一个回答逐条列成「论断、原文摘录、支持到什么程度」，摘录照样经过这道比对。
- 回答里的文字可以拖动选中（跨段也可以），`Ctrl` / `⌘` + `C` 复制，或用回答下面的「复制所选」「引用到输入框」；后者把选中的话作为引用块放进输入框，接着写你的问题。
- 回答正文里的 `[P3 p.5 "…"]` 和回答下面的出处卡片都可以点击：打开这篇文献的 PDF 并跳到所引的页；助手引了原句时，这句话会在页面上高亮（那一页没有就在全文里找，找不到会明说）。筛选建议里的原文依据同样可以点击。
- 一个回答引了很多文献时，下面先列出前 8 个出处，其余的点「另外 N 个出处」展开。
- 输入 `/` 弹出命令列表，继续输入（英文名或中文说明里的字）筛选，↑↓ 选择，Enter 或 Tab 确认：`/search 词语` 在全文和记录里检索；`/cite 一段文字` 为这段文字逐句从库里找可以引用的文献；`/review 主题` 写一段带引用的小综述；`/compare P1 P3` 比较几篇文献的方法和结论；`/new` 开始新对话。
- 常用的提问可以存成自己的命令（设置 › 命令）：起一个名称，写一句说明和一段模板，例如 `/style-check` 检查空泛、重复的表达。模板里的 `{}` 换成命令后面写的内容；不写 `{}` 的模板可以单独使用。自己的命令和内置命令一起出现在列表里，标着「自定义」，选中后不会自动发送。它只是一段提示：不运行脚本，不增加工具，也不绕过确认。对话里保存着当时实际发出的内容，以后修改或删除命令，不会改变旧对话问过什么。
- 支持 Claude API、OpenAI 兼容的 chat/completions 和 OpenAI 的 Responses 接口。
- 单篇提问里，每条回答下面有「存为笔记」：先给你看一遍、可以改，确认后加到这篇文献「我的笔记」的末尾，不覆盖已有内容。对话里的 `[P1 p.5 "…"]` 会去掉只在这次对话里有意义的编号，页码和摘录保留；末尾注明这是模型的回答、没有核对原文。笔记本来就随文献记录一起提供给以后的提问。
- 对话保存在文献库里。没有配置模型时也能看历史对话，只是不能接着问；点「新对话」后会提示上一段已保存。点「历史」列出向文献库（或向这篇文献）提过的问题，点开一次对话可以接着问：模型会按文献库现在的内容重新读材料，以前回答里的 `[P3]` 仍然指向原来那篇文献。历史对话可以逐条删除。

## 设置

单独的设置页（首页或文献库侧栏的「设置」，默认 `Ctrl` / `⌘` + `,`），改动即时保存。

- **通用**：数据目录、自动检查更新。
- **外观**：跟随系统 / 浅色 / 深色，文献列表的行高。
- **快捷键**：搜索、添加文献、导入 PDF、提问、收起侧边栏、PDF 缩放等都可以改键、移除或恢复默认。
- **AI**：可以放进多个模型服务，提问、批量筛选、翻译各用哪一个分别指定（没指定的跟随提问的模型）。三种接口：Claude API、OpenAI 兼容的 chat/completions、OpenAI 的 Responses（/responses）。每个模型有自己的思考设置：默认（不发送参数）、关闭，或低到最高五档；翻译这样的任务可以用一个关闭思考的小模型。模型服务可以单独指定代理，或者填 direct 不走代理。
- **网络**：全局代理（http、https、socks4、socks5 等），文献检索、元数据查询、检查更新和模型请求都经过它；留空时跟随环境变量 ALL_PROXY / HTTPS_PROXY / HTTP_PROXY。命令行 `wisp` 用同一个设置。
- **关于**：版本、检查更新、项目主页。
