# 设计准则：安静的版面

把整个窗口当作一张排好版的纸面，而不是一堆面板的拼贴。这是偏编辑排版（瑞士网格式）的思路，和项目主页做成论文版式、整套配色是暖灰纸面加细线，是同一个气质。

## 五条理念

1. **版面先于组件。** 各栏是同一张版面上的栏，共用同一套基线和通栏线，而不是各自成立的面板。所以一条线接不上不是小瑕疵，而是版面结构错了。
2. **框架恒定，内容退让。** 骨架（栏头的高度、线的位置）不因内容多少、窗口宽窄而动；放不下时是内容自己降级（文字变图标、长句变短语、标签折叠），而不是把框架撑开。界面因此显得稳、静。
3. **一物一貌，一事一言。** 同一个东西在任何模式下长得一样（稿件在两种写作模式里都是白底）；同一件事只在一个地方说一次（#99 去掉了重复的标题和菜单）。"说不清的不一致感"都来自违反这一条的小偏差。
4. **面是连续的。** 每一栏是一整张从窗口顶到底的面，底色和边线贯通，不被标题条截断。层次靠面的明度和细线表达，不靠阴影和装饰。
5. **先安静，后详尽。** 默认只呈现最少的字和图标，完整的说明放在悬停里。界面平时不抢内容的注意力，需要时才展开。

## 操作直觉

版面安静之外，手要不假思索地落对地方。下面几条来自实际点错、看错的地方，新做的页面先对照一遍。

1. **返回在左上，一次只退一级。** 返回放在窗口左上角、红绿灯旁，所有层级都在这一个位置：稿件里是「← 文献库」，文献库里是「← 所有文献库」，设置里是「← 返回」。最上面的箭头永远是最近的一级，不能是跳得更远的那个；一栏里只有一个返回，更远的去处退一级之后自然出现。退一级是整个窗口退一级：侧栏和中间的内容一起回到上一层，回到进来之前的那一页；不能只换侧栏、内容留在原地。连点两下也只退一级。（原先设置的返回在左下；写作页最上面是回首页，回文献库的入口排在它下面，手总是先点到上面那个；后来「← 文献库」只把侧栏换成文献库的导航，稿件还在中间，「写作」还亮着，点了像没退出。）
2. **换页不换边。** 同一组页面共用一个版心：左边线、标题的位置在页与页之间不动。内容窄的页靠版心左侧排，不各自居中。切换时眼睛停在原处，只看内容变化。（原先设置各页按自己的宽度居中，AI 页比别的页宽，一切换左边线就跳 120px。）
3. **控件不受它所改的东西影响。** 用来挑选一项设置的界面，不能因为这项设置的取值而变得不可读、不可用。字体选择器的搜索框和字体名恒用系统字体，字体的样子单列一小段样张。同理，主题、字号、语言的选择处，在任何取值下都得看得清、点得到。改版面的按钮也一样：它放在不随版面移动的地方。交换 PDF 与提问的按钮在两栏共用的标题行里，不在任何一栏里，换过之后它还在原处，再点一下就换回来，指针不用动。（原先字体名用字体自身来画，符号字体的名字是一串图形；选中这种字体后，搜索框里打的字母也不成字母。）
4. **位置先于文字。** 人按位置和习惯操作，不先读标签。所以同一种动作在各处占同一个位置；两个相近的动作不上下紧挨，尤其不能把后果更大的放在更顺手的位置。标签负责说清去处（「文献库」「所有文献库」），而不是都叫「返回」。
5. **导航按「看什么、做什么、管什么」分组，组内按做事的先后排。** 侧栏从上到下三组：同一张文献列表的几种看法（全部文献、最近添加、未读、收藏、缺 PDF）；做事的页面，先是随时可问的助手，再按一篇综述的路径排（检索与导入 → 筛选 → 提取 → 写作）；线以下是管理（自定义词条、回收站、设置）。同一件事只占一行；数字只在大于 0 时出现，它的意思是「这里有事」；两行不共用一个图标。新入口先问它属于哪一组、排在哪一步之后，而不是加在最后。（原先「待判断」和「筛选」是同一批文献，图标相同，数字相同，却分在两组；「提取」是筛选之后的一步，却和回收站、设置一起放在底部；「最近添加」用加号，紧挨着「添加文献」；「收藏 0」「缺 PDF 0」「自定义词条 0」把没事也写成了数字。）
6. **分步的流程：进度在上，下一步在眼前，一步一次点击。** 流程有几步、走到哪一步，用一行进度说清（做完的打勾，跳过的画一横，没到的变淡），它只说状态，不放动作。轮到人做的那一步只放在一个地方：刚读完的内容下面。每一步都在这同一个位置，手不用找；一个决定只点一次，不拆成「记下」和「确认」两下，也不让两下分在页面的两头。没有可做的动作时，这个位置给出能让流程继续的请求，而不是一句「请先……」。模型的回答要被整份采用时，就让模型每次都给出完整的一份，并告诉它按钮叫什么，好让它把人引到按钮上。（原先 /review 的顶栏写着「第 1 步 · 把写作要求记下来」，却没有按钮；要点的「记为要求」是回答下面一个和复制同样淡的小字，点完还要回到顶栏点「确认要求」，再点「提出初步框架」；在对话里回一句「可以」，模型只能说「请在界面确认」，说不出在哪里。）
7. **习惯跟人走，临时的调整跟这一处走。** 人选的方式（PDF 的「适应宽度」「适应整页」）是习惯，换一篇、换窗口大小都保留；为一时之需做的调整（为看一张图放大到 150%）只属于这一处，换一篇就回到习惯。偏离了习惯时，回去的路就在偏离的那个控件旁边，一下就到，用的是菜单里同一个名字；没有偏离时它不出现。（原先手动放大会带到下一篇文献，回到适应宽度要先打开比例菜单再选。）
8. **对选中内容的操作出现在选区旁。** 选中一段文字（回答里的、PDF 上的）之后能做的事，放在松开鼠标的地方：选区末行的下方，靠近边缘时换到首行上方，不盖住选中的字，随内容滚动。不放在回答末尾、栏底或别处的固定一排：长回答里那一排在可见区域之外，选了之后还要去找。同一个动作在选区旁、右键菜单里叫同一个名字（「引用追问」「复制」），也不在选区旁和回答下面各放一份。（原先回答里选中文字后，「引用到输入框」出现在整条回答下面，回答一长就看不到；#128。）
9. **放不下的字要说一声，并且找得回来。** 一行里放不下的文字截在整字上、以「…」结尾，不能由容器裁掉半个字母；被截掉的内容鼠标停上去就能看全，没被截的不出提示。表格的列宽由人拖动表头的分隔线决定并记住，双击分隔线恢复默认，右键表头选择显示哪些列，和 Zotero 等文献工具的习惯一致。整列放不下时也一样：窗口窄了，让出位置的列在「文献」表头末尾记成「+N 列」，悬停说出是哪几列，点它就是选择列的菜单；不能让人选了显示的列无声无息地不见。一行的列表里，文字自带的换行先压成空格（`ui::one_line`），否则它会画到下一行上。（原先 `truncate()` 的文字从不出省略号，题目末尾的 p 只剩一半；列宽固定，长题目没有任何办法看全；打开详情面板后，自定义词条的列和期刊列直接消失，没有任何提示；提取页的原文依据带着 PDF 的换行，压在下一行上。）
10. **怎样看是开关，放在它所改的那块东西上；文中指向别处的东西，停上去先说清，按住键点才去。** 预览只是稿件的另一种看法，它是稿件工具条上「语言」左边的一只眼睛，开着时亮起，再点一下回去；不放进大纲，大纲只列去处。正文里的引用，鼠标停上去在它最后一行下面出一张卡片：是哪篇文献、依据的哪一句、第几页，和「⌘/Ctrl+点击」会去哪里；卡片不盖住引用本身。单击照旧只是放光标，跳走要加 ⌘ / Ctrl，和编辑器里的链接一样。（原先「通读全文」排在大纲底部「参考文献」下面，像一个去处；引用只是一串蓝字，要把光标挪进去才在稿件下面看到出处，打开原文还要再找那一行。）
11. **窄了就换排法，不是把栏挤细；一块地方只有一个滚动。** 每种并排的版面都有放得下的最小宽度（窗口小，或右边开着一篇文献）。不够时主要的那块独占版面，次要的收成抽屉或叠到它下面，随时叫得出来；不能让几栏各剩一百像素、一行一个字。叠起来的各块各自滚动，不再给整页加一层滚动：滚到头的那块会把滚轮交给外层，人明明在滚稿件，动的却是下面的面板。大屏上反过来，多出来的地方留在版心两侧，不把一行字拉得更长。（原先写作页窄于 680px 时把稿件和侧栏各按固定高度叠起来、整页滚动；助手写的对话、稿件、参考文献三栏没有下限，开着文献时各自只剩一个字宽。）
12. **线只画一次。** 一块内容已经由栏线、栏头的线划出了范围，就不再给它套一圈自己的框；框留给浮在别的东西上面、或状态与平时不同的内容（早先的一版、助手的结果）。（原先稿件在自己的栏里又有一圈圆角边框，和栏线重复。）

## 应当避免

"仪表盘式"的做法：每个面板自带标题栏、自定尺寸、各自强调自己。

同一件事在导航里占两行；把流程中的一步和管理项放在一起；用数字 0 占位；同一栏里放两个返回；把返回放在底部或别的需要找的地方；返回只换掉一半版面；每页自己定边距和居中方式；用被预览的字体、颜色去画选择器自身的文字；流程的状态行里写着该做什么却没有按钮；把一个决定拆成两次点击，或把相邻的两步放在页面的两头；把对选中内容的操作放在回答末尾或别处的固定一排。
