# 从 Zotero 导入文献

已经在 Zotero 里整理过文献，可以把本机数据库中的记录和 PDF 复制到 Wisp Paper。打开一个 Wisp Paper 文献库，点左侧「添加文献 › 从 Zotero 导入…」即可开始。新建文献库后的向导也有「从 Zotero 导入」入口。

这个入口读取 Zotero 6 / 7 的本地 `zotero.sqlite`，不需要 Zotero API Key，也不需要配置 AI 模型。它会导入本机个人库和群组库中已同步的文献，不会持续同步后续修改。如果当前安装版本没有这个菜单，需要更新到包含此功能的版本，或从当前源码构建。

## 1. 找到 Zotero 数据目录

在 Zotero 中打开「设置 › 高级 › 文件和文件夹」，点「打开数据目录」。旧版本的设置入口可能叫「首选项」。以这里打开的位置为准，不要选择浏览器配置目录。

默认位置通常是：

| 系统 | 默认数据目录 |
|---|---|
| Windows | `C:\Users\你的用户名\Zotero\` |
| macOS | `/Users/你的用户名/Zotero/` |
| Linux | `/home/你的用户名/Zotero/` |

目录里应当能看到 `zotero.sqlite` 和 `storage` 文件夹。数据库里保存文献信息，`storage` 里保存 Zotero 托管的附件。

等 Zotero 同步完成，打开需要迁移的 PDF，确认文件已经下载到本机。只有云端记录、还没下载的 PDF 无法直接复制。然后退出 Zotero，保留打开的数据目录窗口。

如果使用备份导入，请在退出 Zotero 后复制整个数据目录，保持 `zotero.sqlite` 和 `storage` 的相对位置。只复制数据库能导入记录，但找不到托管的 PDF。链接附件如果保存在这个目录以外，还需要让它们的原路径可访问。

## 2. 选择目标文献库并导入

1. 打开 Wisp Paper，新建或打开要存放这些文献的库，例如「植物单细胞」。首次迁移时可以建一个空库，方便核对结果。
2. 点左侧「添加文献」，选「从 Zotero 导入…」。也可以在新建库向导中直接点「从 Zotero 导入」。
3. 阅读窗口中的说明，点「选择 zotero.sqlite…」，选择上一步找到的数据库文件。
4. 等待导入。窗口显示已处理的篇数和当前文献，PDF 会复制到目标文献库的 `papers/` 目录。

可以点「收起」继续留在当前文献库里操作，左侧下方会保留进度入口。返回首页或切换文献库会停止后续条目的导入；正在复制的条目可能仍会完成，已经导入的内容会保留。之后重新选择同一个数据库即可继续，重复记录和相同内容的附件会去重。

## 3. 看懂导入结果

完成后，结果窗口列出新增文献、已有文献、回收站条目、失败条目、新增 PDF 和待处理问题的数量。逐条查看时，可以看到每篇文献对应的附件问题。点一条已导入或已有的文献，进入详情核对。

| 结果 | 含义 |
|---|---|
| 新增文献 | 记录已加入当前库，初始状态为「待判断」「未读」 |
| 已有文献，保留原记录 | 按 DOI、PMID 或题目识别为重复；不覆盖当前库里的记录、笔记、标签和判断，但可以补入 PDF |
| 在回收站中，未导入 | 当前库的回收站已有这篇；不会自动恢复，也不会向它添加附件 |
| 新增 PDF | 附件已经复制到当前库，可以独立于 Zotero 使用 |
| 已有 PDF | 这篇文献已经有相同内容的附件，不再保存一份 |
| 文献未导入 | 例如题目为空、DOI 格式错误；具体原因在该条下方，其他有效条目仍会继续导入 |
| 待处理 | 例如 PDF 未下载、路径失效或无法复制；文献记录可能已经成功导入 |

一篇文献没有全文时，首个成功复制的 PDF 作为全文；其余 PDF 作为补充附件。导入完成后，Wisp Paper 会在后台读取全文 PDF 的文字。扫描件或无法解析的文件仍会保存，全文状态可能显示「PDF 无文字」，可以在 PDF 页面继续处理。

建议先核对几篇熟悉的文献：题目、作者、DOI 是否正确，标签和笔记是否带入，PDF 能否打开。结果窗口收起后，可以从左侧下方的「Zotero 导入结果 · 查看明细」再次打开；结果保留在本次打开的文献库会话中，切换文献库或退出应用后不会保留这份明细。

## 哪些内容会带入

| Zotero 内容 | 在 Wisp Paper 中的位置或处理方式 |
|---|---|
| 题目、作者、年份、期刊或出版物、DOI、URL、摘要 | 文献的对应字段；作者按 Zotero 原顺序保留，机构作者也支持 |
| Extra 中的 PMID；没有 DOI 字段时 Extra 中的 DOI | 用于对应标识符字段及去重；Extra 原文也保留在笔记中 |
| 标签 | 文献标签 |
| 分类及子分类 | 转为 `Zotero/父分类/子分类` 标签，例如 `Zotero/植物/根`，可在左侧点击筛选 |
| 附属于文献的笔记 | 合并到文献笔记，HTML 转为纯文本；不保留富文本布局和嵌入图片 |
| 已下载的托管 PDF | 从 `storage/附件键/文件名.pdf` 复制 |
| 使用绝对路径的链接 PDF | 路径在当前电脑可访问时复制 |
| Zotero 回收站中的记录、笔记和附件 | 跳过 |
| 订阅源、独立笔记、独立附件、PDF 批注 | 不迁移 |
| 网页快照、图片及其他非 PDF 附件 | 不迁移，结果显示非 PDF 附件的数量 |

Zotero 中的编辑者等非作者角色、卷期页码、条目关联、保存的搜索、彩色标签设置和其他 Wisp Paper 没有对应字段的内容不会迁移。原库仍保留完整信息。

## 常见问题

**只想迁移某个分类或选中的几篇。** 本地数据库入口会读取整个个人库和群组库，不按 Zotero 当前选中的分类过滤。只迁移一部分时，在 Zotero 中右键分类或选中的条目，选择导出，格式选 BibTeX 或 RIS；然后在 Wisp Paper 中用「添加文献 › 导入 BibTeX / RIS…」。这条路线只迁移参考文献记录，不自动带入 PDF，需要在文献详情中另行添加附件。

**提示找不到 PDF。** 先在 Zotero 中打开这份 PDF，确认已经下载且路径有效，再退出 Zotero，重新导入。同一篇记录会保留，之前缺少的 PDF 会补入。若使用数据库备份，检查旁边是否有完整的 `storage` 目录。

**提示“相对链接附件需要基础目录”。** `attachments:` 开头的路径依赖 Zotero 设置中的「链接附件基础目录」，数据库本身没有保存可独立使用的完整路径。当前入口不会猜测这个目录。可以在 Zotero 中将链接附件转换为绝对路径后重试，或在 Wisp Paper 对应文献的附件区手动添加 PDF。

**提示 `database is locked` 或“数据库正在被占用”。** 这表示数据库被 Zotero 或其他进程锁住，不代表文件选错或数据库损坏。在 Zotero 中选择「退出」，等待后台进程结束，再导入同一个 `zotero.sqlite`。Windows 可以在任务管理器中确认 `zotero.exe` 已退出；macOS 用「Zotero › 退出 Zotero」，仅关闭窗口可能仍在后台运行。若退出后仍有锁，检查是否有另一个 Zotero 实例或数据库工具打开着这个文件。不要删除 `-wal` / `-shm` 文件来解锁，里面可能有尚未写回主数据库的更新。

**数据库无法打开或格式不支持。** 确认选择的是 `zotero.sqlite`，不是 `.bak`、导出的 JSON、BibTeX / RIS，或 Wisp Paper 自己的 `wisp-paper.sqlite`。错误原因会留在导入结果中；无法识别的数据库不会作为空库继续处理。

**重新导入后，笔记为什么没更新？** 这是一次复制式迁移。已有记录保留 Wisp Paper 中的内容，重新导入只补 PDF，不把 Zotero 后续修改覆盖进来。需要更新的字段请在 Wisp Paper 中编辑。

**会改动 Zotero 或上传文献吗？** 导入用只读方式打开 Zotero 数据库，只复制 PDF，不移动原文件；这一导入步骤不访问网络、不调用模型。复制完成后，即使原 PDF 被移动，Wisp Paper 保存的副本仍然可用。之后使用 AI、在线检索等功能的数据流向见[数据与隐私](DATA.md)。

导入后，可以继续按[建库教程](TUTORIAL.md#5-让助手筛选)筛选文献、翻译摘要和向文献库提问。
